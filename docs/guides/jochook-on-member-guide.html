01 접속하기

우리 팀 들어가기

운영진이 알려 준 팀 코드와 비밀번호로
선수단과 경기 기록을 조회해요.

조축ON 열기 →

처음 들어갈 때

  1. 위 버튼을 눌러 Safari 또는 Chrome에서 열어요.
  2. 팀 코드와 숫자 6자리 팀 비밀번호를 입력하고 우리 팀 들어가기를 눌러요.
  3. 팀 이름을 확인해요. 우리 팀 홈 →을 누르면 언제든 홈으로 돌아와요.

자주 쓴다면 홈 화면에 추가

아이폰 · Safari 공유 → 홈 화면에 추가.
안드로이드 · Chrome 메뉴 → 앱 설치 또는 홈 화면에 추가.

카카오톡에서 열었다면 Safari·Chrome으로 다시 열어 주세요. 조회에는 인터넷 연결이 필요해요.

접속이 안 된다면

운영진에게 최신 코드·비밀번호를 확인해요. 재시도 대기 시간이 나오면 기다린 뒤 입력해 주세요.

회원은 조회 전용이에요. 팀 코드와 비밀번호는 팀원끼리만 공유하고, 공용 기기에서는 사용 후 ‘나가기’를 눌러 주세요.

02 경기 보기

결과와 스쿼드 확인

최근 경기에서 결과를 열고,
보고 싶은 구간만 펼쳐 보세요.

경기 결과 열기

  1. 홈의 최근 경기 또는 경기 기록에서 날짜·팀명·점수를 보고 경기 행을 눌러요.
  2. 득실점 타임라인에서 쿼터·득점자·도움과 확인된 순서를 봐요.
  3. 스쿼드·교체는 첫 구간만 열려 있어요. 다른 쿼터나 후반의 제목을 눌러 펼쳐요.

상세의 결과 이미지에서 미리 본 뒤 이미지 공유 또는 PNG 다운로드를 직접 선택해요. 저장된 점수·선수 골·도움과 작성 상태가 담겨요.

다른 기간이나 대회 찾기

조회 기간에서 시작월~종료월을 정하고 조회를 눌러요. 경기 구분으로 리그·대회·특정 대회를 골라요.

리그는 정기 경기이며 자체전도 포함돼요. 대회 메뉴에서도 대회를 열고 대회 경기 보기로 이동할 수 있어요.

표시를 이렇게 읽어요

0 : 0은 입력한 무득점, — : —는 미입력이에요. 작성 중 기록은 바뀔 수 있어요.

순서 미기록은 당시 득실점 순서를 확인하지 않은 기록이에요. 정확한 분 단위 시간은 제공하지 않아요.

교체가 있으면 선발·교체 선수가 함께 보여요. 잘못된 기록은 경기 날짜·쿼터·선수를 적어 감독·코치에게 알려 주세요.

03 선수 보기

우리 팀 선수와 기록

이름으로 찾고, 필요한 조건만 바꿔 보세요.

선수단

선수단에서 카드·표 보기를 바꿔요. 상세 정보로 생년·포지션·가입일을 확인해요.

조건 변경을 펼치면 연령대·직책·포지션으로 찾을 수 있어요.

선수 기록

  1. 선수 기록에서 이름·등번호로 검색해요. 기본은 올해의 완료 경기예요.
  2. 조회 기간·경기 조건으로 전체 기간, 리그·대회 등을 골라요. 바꾼 기간은 조회를 눌러 적용해요.
  3. 보기 설정에서 누적·쿼터당 기준, 정렬, 페이지당 인원을 바꿔요. 표는 열 제목으로도 정렬해요.
  4. 선수 이름을 누르면 개인 상세가 열려요. 원본 경기 보기로 해당 경기까지 확인해요.

집계가 궁금하다면

집계 내역·집계 기준 보기를 펼쳐요. 실점은 외부 경기만 집계하며, 미입력 경기는 제외돼요. 경기별 카드는 해당 경기의 실제 골·도움이에요.

간단 보기·표 보기는 기본 10명씩이에요. 이전·다음으로 넘기세요. 상세한 계산 기준은 화면의 접힌 안내에서 확인할 수 있어요.
