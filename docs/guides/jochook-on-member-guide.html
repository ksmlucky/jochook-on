조축ON 열기 →

가입 없이 바로 조회해요

  1. 위 버튼을 눌러 Safari 또는 Chrome에서 열어요.
  2. 팀 코드와 숫자 6자리 팀 비밀번호를 입력해요.
  3. 우리 팀 들어가기를 누르고 팀 이름을 확인해요.

코드는 대소문자·공백·하이픈을 구분하지 않아요. 회원 접속은 조회 전용이에요.

홈 화면에 아이콘 추가하기

카카오톡에서 열었다면 Safari 또는 Chrome으로 다시 열어 주세요. 메뉴 이름은 기기마다 다를 수 있어요.

팀 코드와 비밀번호는 팀원끼리만 공유해 주세요. 앱을 홈 화면에 추가해도 기록 조회에는 인터넷 연결이 필요해요.

02 우리 팀 홈

최근 기록부터 한눈에

홈에서 최근 경기를 보고,
선수 기록과 명단으로 바로 이동해요.

최근 경기에서 바로 열어요

홈의 최근 경기는 최대 3개를 보여요. 날짜·팀명·점수와 작성 상태를 짧게 확인하고, 경기 행이나 점수를 눌러 결과 상세를 열어요.

선수 기록과 명단으로 바로 이동해요

상단 팀 이름 옆 우리 팀 홈 →을 누르면 홈으로 돌아와요. 홈의 선수 기록과 선수단으로 기록·명단을 열고, 전체 경기는 경기 기록 메뉴에서 봐요.

회원 화면은 조회 전용이에요. 작성 중인 경기의 스코어와 실제 기록은 운영진이 입력하는 동안 바뀔 수 있어요.

03 둘러보기

선수단과 경기 기록

보고 싶은 선수를 찾고, 지난 경기에서 누가 어떻게 뛰었는지 확인해 보세요.

선수단 · 보기 편한 방식으로

휴대폰 카드 보기는 한 줄에 2명씩 보여요. 상세 정보를 누르면 생년·선호 포지션·가입일을 펼쳐요. 표 보기는 직책·생년·지망을 묶어 보여요. 옆으로 밀면 가입일도 확인할 수 있어요.

조건 변경을 펼쳐 연령대·직책·1지망 포지션을 고르고, 필터 초기화로 해제해요. 등번호·나이·이름·1지망 순 정렬과 페이지당 10·20·30명 보기도 가능해요.

경기 기록 · 결과부터 확인해요

날짜·팀명·점수를 보고 경기 행을 눌러요. 결과 상세의 득실점 타임라인에서 구간·득점자·도움을 확인하고, 스쿼드·교체에서 배치를 봐요.

첫 구간만 펼쳐져 있어요. 나머지 구간 제목을 눌러 각각 열고 닫아요. 4쿼터는 1~4쿼터, 전후반은 전반·후반으로 보여요. 자체전은 A·B팀을 구분해요.

교체가 있는 자리에 선발과 교체 선수가 함께 보여요. ← 목록으로 돌아가 다른 경기를 확인해요.

포지션 필터와 색상은 1지망 기준이에요. 연령대는 생일과 관계없이 선수단에서는 ‘올해 - 생년’, 경기 상세에서는 ‘경기 연도 - 생년’으로 계산해요.

04 기간과 대회

리그와 대회 찾아보기

매주 하는 경기와 공식 대회를 구분하고,
원하는 기간의 기록만 모아 볼 수 있어요.

리그와 대회는 이렇게 나눠요

리그는 등록한 대회에 연결하지 않은 정기 경기예요. 자체전도 리그에 포함되며, 경기 카드에는 자체전으로 따로 표시돼요.

봄·가을 대회와 K7 같은 공식 대회는 대회로 모아요. 경기 기록의 경기 구분에서 전체·리그만·대회만·특정 대회를 골라요.

기간을 지정해 조회해요

조회 기간을 펼쳐 시작 연월~종료 연월을 고르고 조회를 눌러요. 예: 2026년 3월~6월은 3월 1일부터 6월 30일까지예요. ‘변경한 기간 미적용’이면 아직 이전 결과예요.

경기 기록·대회는 처음에 전체 기간으로 보여요. 선수 기록은 올해가 기본이며, 전체 기간을 누르면 여러 해를 합산해요.

대회 정보에서 경기로 이동해요

대회 메뉴에서 이름·기간·장소·참가 부문·메모를 확인해요. 대회를 열고 대회 경기 보기를 누르면 연결된 경기를 볼 수 있어요.

경기는 실제 경기 날짜로 조회해요. 대회 목록은 대회 기간이 조회 기간과 조금이라도 겹치면 보여요. 선수 통계는 한국 시간 오늘까지의 실제 기록만 합산해요.

05 선수 기록

조회 범위와 정렬

기간과 경기 구분을 고르고 팀·선수 기록을 확인해요.

기본 조회는 올해의 완료 기록이에요

올해 · 리그 + 대회 · 자체전 포함 · 기록 완료만 · 용병 제외가 기본이에요. 기간과 경기 구분을 바꾸고, 경기 조건을 펼쳐 경기 유형·기록 범위·용병 포함을 선택해요.

예전 경기는 완료 + 이전 기록으로 확인해요. 작성 중 포함의 합계는 입력 중에 바뀔 수 있어요.

팀 요약을 읽어요

집계 경기는 매칭·자체전 횟수, 누적 득점은 선수 골 합계, 누적 실점은 외부 매칭만 보여요. 집계 내역을 펼치면 완료·이전·작성 중 경기 수와 집계 안내를 볼 수 있어요.

스코어 미입력은 0실점이 아니에요. 선수 득점 합계는 자책골 등으로 팀 스코어와 다를 수 있어요.

간단 보기와 표를 바꿔 봐요

선수 찾기와 간단 보기·표 보기는 바로 보여요. 표의 열 제목으로도 정렬하고, 이름을 누르면 개인 상세가 열려요.

보기 설정을 펼쳐 스탯 보기·정렬 기준·페이지당 인원을 바꿔요. 닫힌 제목에도 현재 설정이 보여요. 인원은 기본 10명이며 10·20·30명 중 골라요.

이전·다음으로 이동해요. 상세 복귀·보기 전환은 페이지를 유지하고, 검색·정렬·조건 변경은 첫 페이지로 돌아가요.

표를 좌우로 밀면 나머지 항목을 볼 수 있어요. ‘출석 (회)’는 참석·지각한 경기마다 1회예요. 같은 날 두 경기면 2회이며, 출전하지 않아도 포함해요. 참석 예정 투표는 세지 않아요.

06 개인 기록

경기별 기록까지 확인하기

어떤 경기에서 쌓인 골과 도움인지,
선수 이름이나 등번호를 눌러 확인해 보세요.

목록에서 개인 상세로 이동해요

간단 보기의 선수 이름 또는 표의 선수 이름·등번호를 누르면 개인 상세가 열려요. 상세에서도 기간과 리그·대회를 바꿀 수 있고, 시즌 목록으로 돌아가도 최신 조회 조건이 유지돼요.

누적과 쿼터당 기록을 바꿔 봐요

스탯 보기에서 누적 / 1쿼터당 / 2쿼터당 / 3쿼터당 / 4쿼터당을 골라요. 득점·도움·FK·PK에 적용하며 출전·출석은 누적값이에요.

N쿼터당 = 기록 합계 ÷ 실제 출전 쿼터 합계 × N이에요. 출전이 0쿼터면 —로 보여요. 대회 전·후반도 각각 1쿼터이며 분 단위로 환산하지 않아요.

아래 경기 카드는 실제 기록이에요

경기별 기록은 해당 경기의 실제 골·도움 수를 보여요. 프리킥·페널티킥 골이 있을 때만 세부 기록을 덧붙여요. FK·PK는 총 득점에 이미 포함돼요.

원본 경기 보기를 누르면 당시 명단·스쿼드·기록·결과를 조회해요. 이 경로의 원본 화면은 읽기 전용이에요.

1~4쿼터당 수치는 프로 경기의 90분 기록으로 환산한 값이 아니에요. 잘못된 기록은 감독·코치에게 정정을 요청해 주세요. 정정 후 ‘새로고침’으로 다시 확인해요.

07 알아두면 좋아요

기록은 이렇게 읽어요

최종 스코어와 구간별 득실점 흐름을 확인해요.

완료 상태를 확인해요

타임라인은 확인된 득실점 순서만 보여요. 정확한 분은 기록하지 않아요. 순서 미기록인 이전 경기는 구간별 합계를 참고해 주세요. 중간 점수는 추측하지 않아요.

경기는 4쿼터 또는 전·후반 각 30분으로 기록해요. 자체전은 4쿼터예요. 교체한 두 선수는 각 구간을 0.5쿼터씩 나눠요.

작성 상태 확인하기

작성 중 · 마지막으로 저장한 작성 단계예요.
기록 완료 · 운영진이 완료로 표시한 경기예요.
기존 기록 · 상태 미지정 · 예전 기록이라 작성 상태를 따로 정하지 않았어요.

0 : 0은 입력한 무득점 스코어, — : —는 스코어 미입력이에요. 작성 중인 경기의 값은 바뀔 수 있어요.

접속이 안 되거나 기록이 다르다면

코드·비밀번호가 맞지 않으면 운영진에게 최신 정보를 확인해 주세요. 재시도 대기 시간이 나오면 기다린 뒤 입력해 주세요.

정정은 감독·코치에게 경기 날짜, 쿼터, 선수, 바꿀 내용을 알려 주세요. 회원 화면에서는 직접 수정할 수 없어요.

사용 가이드 메뉴에서 목차로 이동하거나 PDF 내려받기로 이 안내서를 받을 수 있어요. 화면의 추가 안내는 제목을 눌러 펼쳐 보세요.

기본 시즌 통계는 기록 완료 경기만 포함해요. 로고가 없으면 기본 배지를 보여요. 회원은 조회만 가능하며 정정은 감독·코치에게 요청해 주세요.
