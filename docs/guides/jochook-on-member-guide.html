01 시작하기

우리 팀 들어가기

선수단과 경기 기록을 휴대폰에서 확인해요.
운영진이 알려 준 팀 코드와 비밀번호를 준비해 주세요.

조축ON 열기 →

가입 없이 바로 조회해요

  1. 위 버튼을 눌러 Safari 또는 Chrome에서 열어요.
  2. 팀 코드와 숫자 6자리 팀 비밀번호를 입력해요.
  3. 우리 팀 들어가기를 누르고 팀 이름을 확인해요.

코드는 대소문자·공백·하이픈을 구분하지 않아요. 회원 접속은 조회 전용이에요.

홈 화면에 아이콘 추가하기

아이폰 · Safari의 공유 메뉴 → 홈 화면에 추가 → 추가. ‘웹 앱으로 열기’가 보이면 켜 주세요.

안드로이드 · Chrome의 점 세 개 메뉴 → 앱 설치 또는 홈 화면에 추가.

카카오톡에서 열었다면 Safari 또는 Chrome으로 다시 열어 주세요. 메뉴 이름은 기기마다 다를 수 있어요.

팀 코드와 비밀번호는 팀원끼리만 공유해 주세요. 앱을 홈 화면에 추가해도 기록 조회에는 인터넷 연결이 필요해요.

02 둘러보기

선수단과 경기 기록

보고 싶은 선수를 찾고, 지난 경기에서 누가 어떻게 뛰었는지 확인해 보세요.

선수단 · 보기 편한 방식으로

카드 보기는 선수별 정보를, 표 보기는 여러 선수의 정보를 비교하기 좋아요. 휴대폰의 표는 옆으로 밀어 볼 수 있어요.

연령대·직책·포지션으로 필터를 걸고, 등번호·나이·이름·1지망 포지션 순으로 정렬해 보세요. 한 페이지에 10·20·30명을 볼 수 있어요.

경기 기록 · 01부터 04까지

목록에서 경기 날짜·시간·상대 팀·스코어·득점자를 확인하고 경기를 열어요.

01 투표·출석 · 참석 예정과 실제 출석
02 스쿼드 계획 · 경기 전 쿼터별 배치
03 실제 출전 · 실제 출전·교체·골·도움
04 결과·코멘트 · 스코어·코멘트·선수별 합계

02·03의 스쿼드 한눈에 보기로 전체 배치를 볼 수 있어요. 쿼터를 고르고 자리를 누르면 선수·교체 정보를 확인해요. 03에서는 골·도움도 보여요. 자체전은 A·B팀을 바꿔 보세요.

포지션 필터와 색상은 1지망 기준이에요. 연령대는 생일과 관계없이 선수단에서는 ‘올해 - 생년’, 경기 상세에서는 ‘경기 연도 - 생년’으로 계산해요.

03 시즌 기록

한 해의 선수 기록

상단 선수 기록에서 득점·도움·출전·참석을 모아 볼 수 있어요.

먼저 집계 범위를 확인해요

기본은 올해 · 외부 경기 · 기록 완료만 · 용병 제외예요. 시즌·경기 유형·기록 범위를 바꾸거나 용병 포함을 선택할 수 있어요.

예전 경기가 빠져 있다면 완료 + 이전 기록을 골라 보세요. 작성 중 포함의 합계는 입력이 끝나기 전까지 바뀔 수 있어요.

보고 싶은 선수와 기록 찾기

이름·등번호로 검색하고 득점·도움·출전 경기·출전 쿼터·실제 참석 순으로 정렬해요. 표는 좌우로 밀어 전체 항목을 볼 수 있어요.

출전 경기는 실제로 뛴 경기 수예요. 실제 참석은 참석·지각한 경기 수로, 출전하지 않은 참석자도 포함해요.

계획이나 미래 경기는 제외해요

한국 시간 오늘까지의 실제 기록을 합산해요. 참석 예정 투표나 02의 계획은 집계하지 않아요.

집계 기준 보기를 펼치면 자세한 기준을 볼 수 있어요. 수정한 기록은 새로고침으로 다시 확인해요.

선수별 득점 합계는 상대 자책골 등으로 팀 스코어와 다를 수 있어요. 현재 기록 정렬은 연말 시상 순위를 확정하는 기능이 아니에요.

04 알아두면 좋아요

기록은 이렇게 읽어요

경기 전 계획과 경기 후 실제 기록을 나눠서 보여 줘요.

계획과 실제는 달라요

02에 이름이 있어도 실제 출전으로 집계되지는 않아요. 실제 출전과 골·도움은 03·04에서 확인해 주세요.

교체 없이 뛰면 1쿼터, 선발과 교체가 있으면 두 선수는 각각 0.5쿼터예요.

작성 상태 확인하기

작성 중 · 마지막으로 저장한 작성 단계예요.
기록 완료 · 운영진이 완료로 표시한 경기예요.
기존 기록 · 상태 미지정 · 예전 기록이라 작성 상태를 따로 정하지 않았어요.

접속이 안 되거나 기록이 다르다면

코드·비밀번호가 맞지 않으면 운영진에게 최신 정보를 확인해 주세요. 재시도 대기 시간이 나오면 기다린 뒤 입력해 주세요.

정정은 감독·코치에게 경기 날짜, 쿼터, 선수, 바꿀 내용을 알려 주세요. 회원 화면에서는 직접 수정할 수 없어요.

사용 가이드 메뉴에서 목차로 이동하거나 PDF 내려받기로 이 안내서를 받을 수 있어요. 화면의 추가 안내는 제목을 눌러 펼쳐 보세요.

공용 기기에서는 사용 후 ‘나가기’를 눌러 주세요. 운영진 개인 계정을 공유받을 필요는 없어요.
