공유용 PDF휴대폰·브라우저에서 읽기

개발할 때 함께 업데이트해요

  1. 기능·문구·권한 변경 시 운영진/회원 가이드의 영향을 검토하고 갱신 대기 목록에 기록해요.
  2. 배포를 확인한 뒤 공통 원본의 사용법과 버전을 수정해요. 아직 로컬에만 있는 기능은 배포용 가이드에 넣지 않아요.
  3. python scripts/Generate-UserGuides.py로 HTML·PDF를 다시 만들어요. Python의 reportlab과 한글 TTF 글꼴이 필요해요. Windows는 맑은 고딕을 사용하고 다른 환경은 --font와 --bold-font를 지정해요.
  4. 실제 화면의 버튼·권한·순서를 대조하고 PDF의 모든 페이지를 이미지로 확인해요. 원본과 결과를 GitHub에 함께 올려요. 가이드 갱신은 앱 배포와 별개예요.

현재 대기: 시즌 기록, 추가 포메이션, 전체화면 스쿼드 편집, 24시간 초안 복원, 간결한 안내문구. 개인정보·계정·팀 코드·비밀번호는 가이드에 포함하지 않아요.
