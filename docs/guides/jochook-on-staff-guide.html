01 시작하기

로그인과 선수단 준비

개인 계정으로 로그인하고
경기에 나올 선수부터 준비해요.

조축ON 열기 →

운영진 로그인

  1. 운영진 로그인에서 개인 아이디·비밀번호를 입력해요.
  2. 현재 팀과 감독·코치 권한을 확인해요. 다른 팀은 팀 · 접속 관리 → 내 팀 목록에서 골라요.

선수 등록·수정

선수단 → 선수 등록에서 이름·포지션을 입력하고 저장해요. 기존 선수는 수정을 눌러요.

여러 명 입력은 한 명으로 시작해요. + 선수 행 추가로 늘리고, 등번호·생년은 목록에서, 가입일은 달력에서 골라요.

파일이 있다면 별도의 엑셀 업로드를 사용해요. 미리보기와 오류를 확인한 뒤 등록해 주세요.

계정 사용

개인 계정은 7일 미사용 시 만료돼요. 서버 재시작 등으로 더 일찍 로그인이 필요할 수 있어요.

아이디·비밀번호를 잊었다면 서비스 관리자에게 본인 확인 후 복구 링크를 요청해요.

선수 명단의 직책과 로그인 권한은 별개예요. 개인 계정을 공유하지 말고 감독·코치마다 본인 계정을 사용해 주세요.

02 경기 입력 · 01단계

경기와 참석 명단

홈의 ‘새 경기 기록’ 또는 경기 기록의
‘경기 기록 등록’으로 시작해요.

경기 기본 정보

외부 경기 또는 자체전을 고르고 날짜·시작 시간을 입력해요. 상대 팀·장소는 선택이에요.

정기 경기는 리그 · 매주 하는 경기예요. 공식 대회는 리그 / 대회에서 골라요. 없다면 + 대회 등록으로 이름·기간을 입력해요.

외부 경기는 4쿼터 또는 전·후반 각 30분 · 2쿼터를 선택해요. 자체전은 4쿼터예요.

참석할 선수를 선택해요

  1. 01단계에서 참석에 투표한 선수를 체크해요. 실제 참석도 함께 반영돼요.
  2. 자체전은 A팀을 고르고 체크한 뒤 B팀을 골라 나머지를 체크해요.
  3. 지각·불참이 생겼다면 불참·지각 등 예외 수정에서 정정해요.
  4. 오른쪽 아래 다음을 눌러 저장하고 02단계로 이동해요.
유형·형식은 배치 전에 확인해 주세요. 대회 등록과 경기 저장은 별개예요. 대회와 경기의 연결도 경기 저장을 눌러야 반영됩니다.

03 경기 입력 · 02단계

스쿼드 배치와 교체

자동으로 시작하거나,
작전판에서 바로 선수를 선택해요.

포메이션과 자동 편성

참석 명단과 포메이션을 확인해요. 자체전은 A·B팀별로 지정할 수 있어요.

1~4쿼터 자동 편성 또는 전·후반 자동 편성을 눌러요. 자체전 자동 편성은 A·B팀을 섞지 않아요. 결과와 경고를 확인해 주세요.

직접 배치·교체하기

  1. 작전판의 자리를 짧게 누르고, 이름순 목록에서 선수를 선택해요. 선택하면 바로 배치돼요.
  2. 선발 아래 + 교체를 누르고 교체 선수를 선택해요.
  3. 배치한 선수를 길게 눌러 다른 자리로 이동하면 이동하거나 두 선수가 자리를 바꿔요.
  4. 쿼터·팀을 바꿔 배치를 확인하고 다음을 눌러 저장해요.

팀원에게 공유하기

스쿼드 이미지를 눌러 미리 본 뒤 이미지 공유 또는 PNG 다운로드를 사용해요. 이미지 공유와 경기 저장은 별개예요.

×로 배치를 해제할 수 있어요. 골·도움 기록이 있는 선수는 해제가 막히니 03단계에서 먼저 기록을 정정해요. 교체한 두 선수는 각각 0.5쿼터로 집계돼요.

04 경기 입력 · 03단계

골·실점 기록과 완료

구간을 고르고 골·도움을 연결하면
선수 기록과 최종 스코어에 반영돼요.

골과 실점 입력

  1. 쿼터 또는 전·후반을 선택해요. 자체전은 A·B팀도 확인해요.
  2. 골 추가를 펼쳐 득점자·도움 선수·골 유형을 고른 뒤 골 추가를 눌러요. 도움은 없어도 돼요.
  3. 외부 경기는 구간별 실점을 입력하거나 - / +로 조절해요. 무실점이면 0을 입력해요. 자체전은 상대 팀 골에서 자동 반영돼요.

순서를 기억한다면

득실점 순서 정하기에서 ↑↓로 골·실점을 옮기고 이 순서로 확인을 눌러요. 모르면 미확인으로 두세요.

1쿼터 기록 저장 등 선택한 구간의 저장 버튼을 눌러요. 골·도움·실점이 바뀌면 순서를 다시 확인해요.

경기가 끝났다면

최종 스코어·선수 기록을 확인하고 코멘트를 남긴 뒤 오른쪽 아래 완료를 눌러요.

목록은 중간 저장, 완료는 기본 시즌 집계에 넣는 확정이에요. 완료 후 중간 저장하면 다시 작성 중으로 바뀌어요.

입력만 하고 나가면 서버에 저장되지 않아요. ‘다음·목록·구간 기록 저장·완료’의 저장 안내를 확인해 주세요. FK·PK는 총 골에 포함되며 승부차기는 제외해요.

05 확인과 이어쓰기

조회·수정·저장 오류

저장한 기록과 아직 저장하지 않은 초안은 달라요.

기록 확인·수정

홈의 최근 경기나 경기 기록을 눌러요. 첫 구간의 원형 등번호·이름·연령대를 보고, 다른 구간이나 선수 명단 · 전체 이름 보기를 펼쳐요.

고치려면 기록 수정을 눌러요. 목록의 변경 이력에서 확인하고, 삭제는 확인창 후 경기 전체를 지워요.

상세의 결과 이미지에서 미리 본 뒤 이미지 공유 또는 PNG 다운로드를 눌러요. 골별 득점자 ← 도움 선수를 확인해요.

선수 기록 확인

선수 기록은 기본 올해·완료 경기예요. 조회 기간·경기 조건을 바꾸고, 보기 설정에서 정렬·인원·쿼터당 기준을 골라요.

선수 이름을 누르면 경기별 실제 기록과 원본 경기 보기가 나와요. 자세한 산식은 집계 기준 보기를 확인해요.

복원·저장 실패

경기 목록의 초안 안내에서 이어서 작성해요. 같은 탭·계정·팀에서 최대 24시간 보관해요.

저장 확인 필요라면 초안 열기 → 저장 결과 확인부터 해요. 확인 전 새 경기로 다시 등록하지 마세요.

충돌 시 최신 기록 보기로 비교해요. 자동으로 덮어쓰지 않으니 필요한 내용을 보관한 뒤 정정해 주세요.

직접 로그아웃하면 초안이 삭제돼요. 보관 실패 경고가 나오면 새로고침·탭 닫기를 하지 말고 내용을 따로 보관해 주세요. 삭제한 경기에는 되돌리기 버튼이 없어요.

06 팀 · 접속 관리

팀원에게 접속 안내하기

조회할 회원과 기록할 운영진의 접속을 구분해요.

회원 코드 · 감독/코치

팀 · 접속 관리 → 팀 접속 코드 관리에서 코드·6자리 비밀번호를 발급해 팀원에게 안내해요.

유효기간은 90일이며 발급 직후 한 번만 보여요. 보관한 값이 없으면 코드·비밀번호 재발급이 필요해요. 기존 코드와 회원 접속은 종료돼요.

팀 로고와 코치 · 감독

팀 로고 → 로고 선택 → 로고 저장으로 등록해요. PNG·JPG, 2MB 이하 파일을 사용해요. 선택만으로 저장되지 않아요.

코치 관리에서 기존 계정을 임명하거나 초대 링크를 만들어 당사자에게 전달해요. 선수 직책만 바꿔서는 권한이 생기지 않아요.

비밀번호·도움말

내 비밀번호 변경에서 바꿀 수 있어요. 로그인할 수 없다면 서비스 관리자에게 본인 확인 후 30분·1회용 복구 링크를 요청해요.

사용 가이드 → PDF 내려받기로 이 안내서를 받아요. 회원에게는 회원용을 공유하고, 더 자세한 기능 설명은 각 화면의 접힌 안내를 펼쳐 보세요.

코드·비밀번호·초대/복구 링크는 공개 문서에 넣지 마세요. 비밀번호 변경·복구 시 다시 로그인해야 하며 미저장 초안도 삭제되니 필요한 내용은 먼저 저장해 주세요.
