01 운영진 접속

우리 팀 기록 관리하기

경기 전에는 참석 선수와 스쿼드를 저장해요.
경기 후 03 결과·코멘트에서 골·도움을 더해요.

조축ON 열기 →

개인 계정으로 로그인해요

  1. 접속 화면에서 운영진 로그인을 눌러요.
  2. 개인 아이디·비밀번호로 로그인해요.
  3. 현재 팀과 감독·코치 권한을 확인해요. 여러 팀에 속했다면 팀 · 접속 관리 → 내 팀 목록에서 선택해요.

처음 초대받았다면

초대 링크에서 팀과 권한을 확인한 뒤, 아이디와 12자 이상 비밀번호를 정하고 계정 설정 · 팀 참여를 눌러요. 이미 계정이 있으면 기존 계정으로 로그인하고 수락해요.

초대는 24시간 동안 한 번 사용할 수 있어요. 만료된 초대는 관리자에게 다시 요청해 주세요. 아이디·비밀번호를 잊었다면 이 가이드의 비밀번호 변경과 복구를 확인해 주세요.

감독·코치는 선수와 경기 기록을 관리해요. 감독은 코치도 임명할 수 있어요. 선수 명단의 직책만 바꿔서는 로그인 권한이 생기지 않아요.

02 로그인 유지

로그인과 기기 사용

개인 계정은 7일 동안 사용하지 않으면 만료돼요.
공용 기기에서는 사용 후 로그아웃해 주세요.

운영진 개인 계정

마지막 서버 요청부터 7일 미사용이면 다시 로그인해요. 앱에서 서버로 요청하면 유지 시간이 갱신돼요.

서버가 재시작되거나 브라우저가 세션 쿠키를 지우면 7일 전에도 다시 로그인해야 해요. 영구 로그인 기능은 아니에요.

회원 공유 코드 접속

회원 코드로 들어온 접속은 기존대로 24시간 미사용 또는 로그인 후 최대 7일이면 만료돼요. 운영진 개인 계정과 기준이 달라요.

계정 보호는 그대로예요

비밀번호 변경·계정 비활성화·접속 권한 변경 등으로 로그인이 종료될 수 있어요.

저장하지 않은 경기 입력이 있다면 복원 안내를 먼저 확인해 주세요. 공용 기기에서는 작업을 저장하고 직접 로그아웃해요.

아이디·비밀번호를 다른 운영진과 공유하지 마세요. 개인 계정의 권한과 선수 명단의 직책은 별개예요.

03 우리 팀 홈

저장한 경기 이어서 작성

최근 경기를 확인하고, 다음 입력을 바로 시작해요.

최근 경기에서 바로 열어요

홈의 최근 경기는 최대 3개를 보여요. 날짜·팀명·점수와 작성 상태를 짧게 확인하고, 경기 행이나 점수를 눌러 결과 상세를 열어요.

상세는 조회 전용이에요. 고치려면 상단의 기록 수정을 누르고, ← 목록으로 목록에 돌아가요.

결과와 스쿼드를 나눠 봐요

득실점 타임라인은 확인한 순서만 보여요. 스쿼드·교체는 첫 구간만 열려 있고, 다른 구간은 제목을 눌러 펼쳐요. 전후반·자체전 A/B도 구분해요.

선수 기록과 명단으로 바로 이동해요

홈의 선수 기록으로 득점·도움·출전을, 선수단으로 팀 명단을 확인해요. 전체 경기 목록은 경기 기록 메뉴에서 볼 수 있어요.

새 경기와 이어서 작성 · 감독/코치

새 경기 기록으로 입력을 시작해요. 이어서 작성에는 최근 10경기 중 작성 중으로 저장한 경기를 최대 2개 보여 줘요.

저장하지 않은 초안은 홈 목록과 달라요. 경기 기록 화면의 복원 안내에서 먼저 이어 쓰거나 버릴지 선택해 주세요.

홈에 보이지 않는 경기도 경기 기록 목록에서 찾을 수 있어요. 상태 미지정인 예전 기록은 작성 중으로 추측해 표시하지 않아요.

04 경기 전에

선수단 준비하기

선수를 먼저 등록하면 경기마다 명단에서 편하게 선택할 수 있어요.

한 명 등록하거나 수정하기

  1. 카드는 한 줄에 2명, 표 보기는 직책·생년·지망을 묶어 보여요. 선수 등록 또는 기존 카드·표의 수정을 눌러요.
  2. 이름·기본 포지션·1지망을 입력해요. 포지션을 모르면 기본 포지션을 미확인으로 두고 지망을 비워요.
  3. 등번호·생년·직책·가입일과 2·3지망을 확인한 뒤 선수 등록하기 또는 변경 사항 저장을 눌러요.

입력 기준

등번호는 1~99 중 남는 번호를 골라요. 여러 명 입력은 등번호·생년 모두 목록에서만 선택해요. 선택한 번호는 다른 행 목록에서 빠져요.

생년 목록은 1950년~올해 17세가 되는 출생연도예요. 한 명 등록은 직접 입력도 가능해요. 번호·생년을 모르면 비워 두세요.

2·3지망은 선택이고 같은 포지션을 중복 선택할 수 없어요. 직책은 정회원·코치·감독·총무·회장 중 하나예요.

여러 명 한 번에 등록하기

여러 명 입력은 1명으로 시작해요. + 선수 행 추가로 늘리고 가입일은 달력에서 골라요. 검토 후 ○명 전체 등록을 눌러요.

엑셀 업로드에는 행 추가 버튼이 없어요. 파일을 불러와 수정·검토 후 등록해요. 최대 200명, .xlsx·2MB 이하예요.

연령대는 생일과 관계없이 연도에서 생년을 뺀 기준이에요. 예: 2026년 - 1996년 = 30세, 30대.

05 대회 관리

대회를 등록하고 연결하기

매년 참가하는 대회도 연도별로 등록하면
경기와 선수 기록을 따로 모아 볼 수 있어요.

대회 정보를 등록해요

  1. 대회 → 대회 등록을 눌러요.
  2. 대회 이름·시작일·종료일을 입력해요. 장소·참가 부문·메모는 선택이에요.
  3. 대회 등록으로 저장해요. 변경할 때는 대회 정보 수정 → 대회 정보 저장을 눌러요.

해마다 별도 대회로 관리해요

예: 2026 봄대회, 2026 가을대회, 2027 K7을 각각 등록해요. K7처럼 이름에 리그가 있어도 공식 대회는 등록한 대회로 모아요.

경기에 대회와 단계를 연결해요

경기 입력의 리그 / 대회에서 대회를 골라요. 없으면 + 대회 등록으로 만들 수 있고 경기 초안은 유지돼요. 대회는 즉시 등록되지만, 경기와의 연결은 경기 저장을 눌러야 반영돼요.

매주 하는 경기라면 리그 · 매주 하는 경기를 선택해요. 자체전도 리그에 포함돼요. 대회 경기 보기에서 연결된 경기를 확인해요.

대회 정보는 감독·코치가 등록·수정해요. 현재 대회 삭제·참가 연령 자격 자동 판정·승부차기는 지원하지 않아요. 대회 연결을 해제해도 이미 저장한 경기 형식은 유지돼요.

06 경기 기본 정보

경기 형식과 대회 선택

홈의 새 경기 기록 또는 경기 기록 → 경기 기록 등록에서 시작해요. 기존 경기는 기본 정보 요약을 눌러 펼칠 수 있어요.

유형과 시간을 정해요

외부 경기 · 리그 / 대회 또는 자체전 · A팀 vs B팀을 골라요. 유형은 경기 전체에 적용되며 배치·스코어 입력 후 또는 저장 후에는 바꿀 수 없어요.

날짜와 시작 시간은 필수예요. 시·분을 따로 선택하고 분은 00·30 중 골라요. 상대 팀과 장소는 선택이에요.

외부 경기의 형식을 선택해요

외부 경기는 대회 연결 없이도 4쿼터 또는 전·후반 각 30분 · 2쿼터를 골라요. 새 경기에서 대회를 고르면 전·후반이 기본이에요. 자체전은 4쿼터예요.

4쿼터는 시작+2시간, 전·후반은 시작+60분으로 표시해요. 전·후반의 휴식 시간은 표시 범위에 포함하지 않아요.

기존 4쿼터 기록은 보존해요

예전 대회 경기는 자동으로 2쿼터로 바뀌지 않아요. 3·4쿼터 계획이나 실제 기록이 있으면 전·후반으로 전환할 수 없어요. 필요한 기록인지 먼저 확인해 주세요.

전반·후반을 각각 1쿼터로 세고, 한 자리에서 교체한 두 선수는 각 0.5쿼터예요. 대회 풀타임은 2쿼터이며 리그와 합산할 때 시간으로 환산하지 않아요. 참석 명단 → 스쿼드·기록 → 결과의 3단계예요.

07 경기 입력 · 01단계

참석 명단과 A·B팀 선택

카카오톡 투표를 직접 옮겨 적어요.
자체전은 팀을 먼저 고르고 선수를 체크해 주세요.

외부 경기는 참석 예정자를 골라요

이름·등번호로 검색해 참석에 투표한 선수 카드를 선택해요. 선택하면 실제 참석도 함께 반영돼요. 따로 출석을 확정할 필요는 없어요.

자체전은 A팀부터, 다음에 B팀

  1. A팀을 누르고 선수를 체크해요. 참석과 팀 배정이 함께 반영돼요.
  2. B팀을 누르고 나머지 선수를 체크해요. 다른 팀 선수는 중복 선택할 수 없어요.
  3. 팀 이동·선택 해제 시 배치 정리 안내를 확인해요. 골·도움이 있는 선수는 기록을 먼저 확인해 주세요.

예외만 수정하고 저장해요

지각·불참 등 달라진 경우에만 출석 상세에서 정정해요.

오른쪽 아래 다음을 누르면 저장 후 02로 이동해요.

자동 편성 전 참석 명단과 자체전 A·B팀을 확인해 주세요. 기록이 있는 선수를 해제하려면 먼저 골·도움 등 기록을 정정해야 해요.

08 스쿼드 준비

포메이션 선택하기

경기 기본 정보 아래에서 포메이션을 고르고
참석 인원에 맞춰 스쿼드를 짜요.

6가지 구성 중에서 선택해요

4-1-2-3 · 수비형 미드필더 1명
4-4-2 · 수비·미드필더 두 줄과 공격수 2명
4-2-3-1 · 수비형 2명·공격형 1명
4-1-4-1 · 수비형 1명·미드필더 4명
3-5-2 · 수비 3명·윙백·CM 2명·CAM·ST 2명
3-4-3 · 수비 3명·LM/RM·CM 2명·LW/ST/RW

같은 팀의 모든 구간에 적용해요

02 스쿼드의 모든 구간에 같은 포메이션을 써요. 자체전은 A·B팀별로 선택할 수 있어요.

선호 포지션에는 LM·RM·CAM·LWB·RWB도 선택할 수 있어요. 중앙 수비/미드필더의 좌우 자리는 CB·CM·CDM 지망으로 연결돼요.

이미 배치했다면 변경 내용을 확인해요

배치 후 변경하면 공통 자리의 선수는 유지하고, 사라지는 자리의 배치는 해제해요. 참석 명단은 유지돼요.

골·도움 등 기록이 사라지는 변경은 차단해요. 해당 기록을 먼저 확인하고 필요한 정정을 해 주세요.

3-5-2 작전판은 CAM을 두 공격수 뒤에 두고, LWB·RWB를 중앙 수비보다 높게 표시해요. 중앙 수비의 LCB·CB·RCB 자리는 CB 지망으로 연결돼요.

09 경기 입력 · 02단계

스쿼드 배치와 교체

자동 편성하거나 자리를 눌러 선수를 골라요.
골·도움은 다음 03단계에서 입력해요.

자동 편성으로 시작하기

명단 확인 후 1~4쿼터 자동 편성 또는 전·후반 자동 편성을 눌러요. 자체전은 A·B팀 1~4쿼터 자동 편성으로 팀을 섞지 않고 각각 계산해요.

선호 포지션·출전 배분·과거 출석률을 고려해요. GK 지망이 있는 선수는 GK 그룹이에요. 모두 전 구간에 참여할 수 있을 때 사용하고 경고·배분을 확인해 주세요.

배치·교체를 직접 바꾸기

  1. 자리를 누르고 이름순 목록의 선수를 선택해요. 바로 배치되고 창이 닫혀요. 선발을 해제하면 기존 교체가 선발로 올라와요.
  2. 선발이 있는 자리의 + 교체를 누르고 교체 선수를 골라요. 배치된 선수는 색상과 현재 자리로 구분해요.
  3. 선수를 길게 누른 뒤 다른 자리로 끌어요. 빈자리로 이동하거나 두 선수가 바뀌어요. 한눈에 보기에서도 같아요.
  4. 이전 쿼터 스쿼드 복사로 이어 써요. 골 기록이 사라지는 복사는 차단돼요.

용병·자체전도 기록해요

목록에서 개인 상세로 이동해요

간단 보기의 선수 이름 또는 표의 선수 이름·등번호를 누르면 개인 상세가 열려요. 상세에서도 기간과 리그·대회를 바꿀 수 있고, 시즌 목록으로 돌아가도 최신 조회 조건이 유지돼요.

누적과 쿼터당 기록을 바꿔 봐요

스탯 보기에서 누적 / 1쿼터당 / 2쿼터당 / 3쿼터당 / 4쿼터당을 골라요. 득점·도움·FK·PK에 적용하며 출전·출석은 누적값이에요.

N쿼터당 = 기록 합계 ÷ 실제 출전 쿼터 합계 × N이에요. 출전이 0쿼터면 —로 보여요. 대회 전·후반도 각각 1쿼터이며 분 단위로 환산하지 않아요.

아래 경기 카드는 실제 기록이에요

경기별 기록은 해당 경기의 실제 골·도움 수를 보여요. 프리킥·페널티킥 골이 있을 때만 세부 기록을 덧붙여요. FK·PK는 총 득점에 이미 포함돼요.

원본 경기 보기를 누르면 당시 명단·스쿼드·기록·결과를 조회해요. 이 경로의 원본 화면은 읽기 전용이에요.

원본 연결 화면은 운영진에게도 읽기 전용이에요. 정정하려면 ‘경기 기록’ 메뉴에서 해당 경기를 수정·저장하고 선수 기록을 새로고침해 주세요. 출석률·연말 시상·프로 90분 비교는 별도 정책이에요.

팀 · 접속 관리

우리 팀 로고 등록하기

감독이 팀 로고를 등록하면
팀원도 경기 목록과 결과에서 볼 수 있어요.

감독 계정에서 등록해요

  1. 팀 · 접속 관리 → 팀 로고를 열어요.
  2. 로고 선택으로 PNG 또는 JPG 파일을 고르고 미리보기를 확인해요.
  3. 로고 저장을 눌러요. 다른 파일을 선택해 같은 방법으로 바꿀 수 있어요.

파일 기준

파일은 2MB 이하, 가로·세로 각각 4,096픽셀 이하여야 해요. 앱이 비율을 유지해 256×256 PNG로 정리해요. 남는 공간은 투명 여백이에요.

기본 배지로 돌아가려면

로고 삭제를 누르고 확인창을 확인해요. 삭제하면 팀명을 나타내는 기본 배지로 돌아가요.

코치와 회원은 로고를 볼 수 있지만 바꿀 수 없어요. 상대 팀 로고 등록은 아직 지원하지 않아요.

팀에서 사용할 권한이 있는 로고를 선택해 주세요. 파일 선택만으로 저장되지 않으니 미리보기 후 로고 저장을 눌러요.

16 팀 · 접속 관리

팀원·코치에게 권한 주기

회원은 팀 코드로 조회하고,
감독·코치는 개인 계정으로 기록을 관리해요.

회원에게 코드 안내하기 · 감독/코치

  1. 팀 · 접속 관리 → 팀 접속 코드 관리를 열어요.
  2. 코드·비밀번호를 발급하고, 표시된 내용을 보관해요.
  3. 팀원에게 코드와 6자리 비밀번호를 함께 안내해요. 사용 가이드 → PDF 내려받기로 안내서도 받을 수 있어요.

유효기간은 90일이며 발급 직후 한 번만 보여요. 점 표시는 눌러도 열리지 않아요. 보관한 코드가 없다면 코드·비밀번호 재발급을 눌러요. 기존 코드·비밀번호와 회원 접속은 종료돼요.

코치 임명하기 · 감독

팀 · 접속 관리 → 코치 관리에서 기존 계정의 정확한 로그인 아이디를 입력하고 코치 임명을 눌러요.

계정이 없다면 코치 초대 만들기로 24시간 일회용 링크를 발급해 당사자에게 전달해요.

권한을 해제하려면 조회 회원으로 변경을 눌러요. 기존 경기 기록은 유지돼요. 감독 권한 변경은 서비스관리자에게 요청해 주세요.

선수 직책과 로그인 권한은 별개예요. 회원에게는 회원용 가이드를 전달해 주세요. 비밀번호·팀 코드·초대 링크는 가이드에 넣지 말고 대상자에게 별도로 안내해 주세요.

17 개인 계정

비밀번호 변경과 복구

팀 공유 비밀번호와 개인 계정 비밀번호는 달라요.

로그인할 수 있다면 직접 바꿔요

  1. 메뉴의 내 비밀번호 변경을 열어요.
  2. 현재 비밀번호와 새 비밀번호·확인을 입력하고 비밀번호 변경을 눌러요.
  3. 새 비밀번호로 다시 로그인해요. 다른 기기의 개인 로그인도 종료돼요.

새 비밀번호는 이전과 다르게, 12자 이상·72바이트 이내로 정해요. 한글은 보통 한 글자당 3바이트예요.

아이디·비밀번호를 잊었다면

서비스 관리자에게 기존 연락 경로로 본인 확인을 요청해요. 관리자가 대상 계정을 확인하고 30분 동안 한 번 사용할 수 있는 복구 링크를 직접 전달해요. 이메일 자동 발송은 없어요.

링크의 계정과 기한을 확인하고 새 비밀번호·확인을 입력한 뒤 새 비밀번호 저장을 눌러요. 완료 후 새 비밀번호로 다시 로그인해요.

링크를 사용할 수 없다면

만료·사용된 링크는 다시 요청해 주세요. 새 링크를 받으면 이전 링크는 사용할 수 없어요. 화면을 새로고침했다면 원래 받은 링크를 다시 열어 주세요.

변경·복구를 완료하면 이 탭에 보관한 개인 계정의 미저장 초안도 삭제돼요. 필요한 기록은 먼저 저장해 주세요. 저장된 경기와 팀 공유 비밀번호는 유지돼요.

18 서비스 관리자 전용

운영진 복구 링크 발급

이 기능은 감독·코치 메뉴가 아닌
서비스 관리자 전용 기능이에요.

본인을 확인한 뒤 발급해요

  1. 기존에 확인된 연락처 등으로 요청자가 계정의 본인인지 확인해요.
  2. 팀 · 접속 관리 → 운영진 계정 복구에서 아이디를 검색하고 팀·역할을 대조해 대상 계정을 선택해요.
  3. 본인 확인 항목을 체크하고 복구 링크 발급 → 확인 후 발급을 눌러요.
  4. 복구 링크 복사로 복사해 확인한 당사자에게만 전달하고 확인했어요 · 닫기를 눌러요.

발급 대상과 유효기간

활성 팀의 활성 감독·코치 계정이 대상이에요. 서비스 관리자 자신의 계정은 이 기능으로 복구할 수 없어요.

링크는 30분·1회용이고 발급 화면에서만 확인할 수 있어요. 재발급하면 이전 미사용 링크가 폐기돼요. 링크를 열기만 해서는 사용 처리되지 않아요.

완료 후에는 다시 로그인해요

상대가 새 비밀번호 저장을 완료하면 대상 계정의 기존 로그인이 종료돼요. 비밀번호 원문을 관리자에게 전달받거나 대신 보관하지 않아요.

팀 공유 코드 재발급·코치 초대와는 다른 기능이에요. 복구 링크를 단체 채팅이나 공개 문서에 올리지 마세요.
