01 운영진 접속

우리 팀 기록 관리하기

경기 전에는 명단과 계획을,
경기 후에는 실제 출전과 결과를 남겨요.

조축ON 열기 →

개인 계정으로 로그인해요

  1. 접속 화면에서 운영진 로그인을 눌러요.
  2. 개인 아이디·비밀번호로 로그인해요.
  3. 현재 팀과 감독·코치 권한을 확인해요. 여러 팀에 속했다면 팀 · 접속 관리 → 내 팀 목록에서 선택해요.

처음 초대받았다면

초대 링크에서 팀과 권한을 확인한 뒤, 아이디와 12자 이상 비밀번호를 정하고 계정 설정 · 팀 참여를 눌러요. 이미 계정이 있으면 기존 계정으로 로그인하고 수락해요.

초대는 24시간 동안 한 번 사용할 수 있어요. 만료됐거나 비밀번호를 잊었다면 초대해 준 관리자에게 문의해 주세요.

감독·코치는 선수와 경기 기록을 관리해요. 감독은 코치도 임명할 수 있어요. 선수 명단의 직책만 바꿔서는 로그인 권한이 생기지 않아요.

02 경기 전에

선수단 준비하기

선수를 먼저 등록하면 경기마다 명단에서 편하게 선택할 수 있어요.

한 명 등록하거나 수정하기

  1. 선수단 → 선수 등록을 눌러요. 기존 선수는 카드·표의 수정을 눌러요.
  2. 이름·기본 포지션·1지망을 입력해요. 포지션을 모르면 기본 포지션을 미확인으로 두고 지망을 비워요.
  3. 등번호·생년·직책·가입일과 2·3지망을 확인한 뒤 선수 등록하기 또는 변경 사항 저장을 눌러요.

입력 기준

등번호는 1~99를 직접 입력하거나 남는 번호 목록에서 골라요. 활동 선수끼리 중복할 수 없고, 여러 명 입력에서 고른 번호는 다른 행의 목록에서 빠져요.

생년은 직접 입력하거나 1950년~올해 17세가 되는 출생연도 목록에서 골라요. 2026년에는 2009년생까지예요. 번호·생년을 모르면 비워 두세요.

2·3지망은 선택이고 같은 포지션을 중복 선택할 수 없어요. 직책은 정회원·코치·감독·총무·회장 중 하나예요.

여러 명 한 번에 등록하기

여러 명 입력으로 행을 추가하거나 엑셀 업로드에서 양식을 받아 작성해요. 검토 오류를 고친 뒤 ○명 전체 등록을 눌러야 저장돼요.

최대 200명 · .xlsx · 2MB 이하. 일괄 등록은 새 선수 추가용이에요.

연령대는 생일과 관계없이 연도에서 생년을 뺀 기준이에요. 예: 2026년 - 1996년 = 30세, 30대.

03 대회 관리

대회를 등록하고 연결하기

매년 참가하는 대회도 연도별로 등록하면
경기와 선수 기록을 따로 모아 볼 수 있어요.

대회 정보를 등록해요

  1. 대회 → 대회 등록을 눌러요.
  2. 대회 이름·시작일·종료일을 입력해요. 장소·참가 부문·메모는 선택이에요.
  3. 대회 등록으로 저장해요. 변경할 때는 대회 정보 수정 → 대회 정보 저장을 눌러요.

해마다 별도 대회로 관리해요

예: 2026 봄대회, 2026 가을대회, 2027 K7을 각각 등록해요. K7처럼 이름에 리그가 있어도 공식 대회는 등록한 대회로 모아요.

경기에 대회와 단계를 연결해요

경기 입력의 리그 / 대회에서 등록한 대회를 고르고, 필요하면 예선·8강·준결승·결승 등 단계를 선택해요. 경기 저장을 눌러야 연결돼요.

매주 하는 경기라면 리그 · 매주 하는 경기를 선택해요. 자체전도 리그에 포함돼요. 대회 경기 보기에서 연결된 경기를 확인해요.

대회 정보는 감독·코치가 등록·수정해요. 현재 대회 삭제·참가 연령 자격 자동 판정·승부차기는 지원하지 않아요. 대회 연결을 해제해도 이미 저장한 경기 형식은 유지돼요.

04 경기 기본 정보

리그 4쿼터 · 대회 전후반

경기 기록 → 경기 기록 등록에서 시작해요.
경기 유형과 형식을 먼저 확인해 주세요.

유형과 시간을 정해요

외부 경기 · 리그 / 대회 또는 자체전 · A팀 vs B팀을 골라요. 유형은 경기 전체에 적용되며 배치·스코어 입력 후 또는 저장 후에는 바꿀 수 없어요.

날짜와 시작 시간은 필수예요. 시·분을 따로 선택하고 분은 00·30 중 골라요. 상대 팀과 장소는 선택이에요.

새 대회는 전·후반 각 30분이에요

새 경기에서 대회를 고르면 전반(1쿼터)·후반(2쿼터)으로 시작해요. 리그와 자체전은 4쿼터예요. 대회는 필요에 따라 경기 형식에서 4쿼터를 고를 수 있어요.

4쿼터는 시작+2시간, 대회 전·후반은 시작+60분으로 표시해요. 전·후반의 휴식 시간은 표시 범위에 포함하지 않아요.

기존 4쿼터 기록은 보존해요

예전 대회 경기는 자동으로 2쿼터로 바뀌지 않아요. 3·4쿼터 계획이나 실제 기록이 있으면 전·후반으로 전환할 수 없어요. 필요한 기록인지 먼저 확인해 주세요.

전반·후반을 각각 1쿼터로 세고, 한 자리에서 교체한 두 선수는 각 0.5쿼터예요. 대회 풀타임은 2쿼터이며 리그와 합산할 때 시간으로 환산하지 않아요. 입력 단계 01~04는 그대로예요.

05 경기 입력 · 01단계

참석 명단과 A·B팀 선택

카카오톡 투표를 직접 옮겨 적어요.
자체전은 팀을 먼저 고르고 선수를 체크해 주세요.

외부 경기는 참석 예정자를 골라요

이름·등번호로 검색해 참석에 투표한 선수 카드를 선택해요. 선택한 선수만 보기로 확인해요. 선택을 해제하면 미투표로 돌아가요.

자체전은 A팀부터, 다음에 B팀

  1. A팀을 누르고 A팀 선수를 체크해요. 참석 예정과 팀 배정이 함께 설정돼요.
  2. B팀을 누르고 B팀 선수를 체크해요. 다른 팀에 배정된 선수는 중복 체크할 수 없어요.
  3. 옮길 때는 A팀으로 이동 / B팀으로 이동을 눌러 확인해요. 기존 계획에 배치한 선수의 팀 변경·해제는 계획 정리 안내를 확인해 주세요.

실제 출석을 확인하고 저장해요

투표 상세·실제 출석 입력 펼치기에서 불참 예정·미정 투표와 실제 참석·지각·불참·미확인을 입력해요.

투표 저장 · 스쿼드 계획으로를 누르면 저장 후 02로 이동해요. 미배정이 남아 있어도 중간 저장은 할 수 있어요.

체크 해제는 미투표로 돌아가지만 실제 출석·출전·득점은 유지돼요. 팀 변경 때 충돌하는 계획 배치만 해제해요. 자동 편성 전에는 참석 예정자를 A·B팀에 모두 배정해 주세요.

06 스쿼드 준비

포메이션 선택하기

경기 기본 정보 아래에서 포메이션을 고르고
참석 인원에 맞춰 스쿼드를 짜요.

6가지 구성 중에서 선택해요

4-1-2-3 · 수비형 미드필더 1명
4-4-2 · 수비·미드필더 두 줄과 공격수 2명
4-2-3-1 · 수비형 2명·공격형 1명
4-1-4-1 · 수비형 1명·미드필더 4명
3-5-2 · 수비 3명·윙백·CM 2명·CAM·ST 2명
3-4-3 · 수비 3명·LM/RM·CM 2명·LW/ST/RW

같은 팀의 모든 구간에 적용해요

선택한 포메이션을 02 계획과 03 실제 출전의 모든 구간에 써요. 구간별로 다르게 정하지는 않아요. 자체전은 A팀·B팀의 포메이션을 각각 고를 수 있어요.

선호 포지션에는 LM·RM·CAM·LWB·RWB도 선택할 수 있어요. 중앙 수비/미드필더의 좌우 자리는 CB·CM·CDM 지망으로 연결돼요.

이미 배치했다면 변경 내용을 확인해요

계획이 있으면 확인창이 나와요. 공통 자리의 선수는 유지하고, 새 포메이션에 없는 자리의 계획 배치는 해제해요. 선수는 참석 명단에 남아요.

해당 팀에 실제 출전 기록이 있으면 변경이 잠겨요. 꼭 바꿔야 한다면 03의 출전·골·도움을 확인하고 직접 배치를 해제한 뒤 변경해요.

3-5-2 작전판은 CAM을 두 공격수 뒤에 두고, LWB·RWB를 중앙 수비보다 높게 표시해요. 중앙 수비의 LCB·CB·RCB 자리는 CB 지망으로 연결돼요.

07 경기 입력 · 02단계

쿼터별 스쿼드 계획

리그는 4쿼터, 대회는 전·후반을 준비해요.
배치와 출전량을 확인한 뒤 저장해 주세요.

자동 편성으로 시작하기

명단 확인 후 1~4쿼터 자동 편성 또는 전·후반 자동 편성을 눌러요. 자체전은 A·B팀 1~4쿼터 자동 편성으로 팀을 섞지 않고 각각 계산해요.

선호 포지션·출전 배분·과거 출석률을 고려해요. GK 지망이 있는 선수는 GK 그룹이에요. 모두 전 구간에 참여할 수 있을 때 사용하고 경고·배분을 확인해 주세요.

배치·교체를 직접 바꾸기

  1. 구간을 고르고 선수 카드 → 자리를 눌러 배치해요. 스쿼드 한눈에 보기에서는 자리를 눌러 선발·교체를 바로 고를 수 있어요.
  2. 일반 화면은 선수 카드를 고른 뒤 + 교체를 눌러요. 한눈에 보기에서는 해당 자리의 교체 선수를 골라요.
  3. 앞 구간과 같게 쓰려면 이전 쿼터 계획 복사를 눌러요. 자체전의 이전 쿼터 양 팀 계획 복사는 양 팀을 함께 바꿔요.

용병·자체전도 기록해요

+ 용병 추가에서 기존 용병을 고르거나 등록해요. 이름은 필수, 등번호는 선택이에요. 용병 정보는 즉시 저장되고 참가·배치는 경기 저장 때 반영돼요.

자체전 02의 선수 후보는 01에서 정한 팀 안에서만 보여요. 팀 자체를 옮기려면 01로 돌아가 변경해 주세요.

한눈에 보기의 ‘입력 완료 · 작전판으로’는 창을 닫아요. 전체보기를 닫고 ‘계획 저장 · 실제 기록으로’를 눌러야 저장돼요. 계획은 실제 출전 집계와 별개예요.

08 경기 입력 · 03단계

실제 출전·골·도움

계획대로 뛰었다면 복사하고,
달라진 선수와 기록만 고쳐 주세요.

계획대로 뛰었다면

02 계획대로 참석·출전 기록 저장을 누르면 계획을 실제 출전으로 복사하고 현재 입력 내용 전체를 저장해요. 참석 예정자의 미확인 출석은 참석으로, 골·도움·FK·PK는 0으로 시작해요.

지각·불참은 유지돼요. 불참 선수가 계획에 있으면 먼저 정정해 주세요. 이미 실제 출전 기록이 있으면 일괄 복사는 할 수 없어요.

휴대폰에서 기록 고치기

  1. 쿼터 또는 전·후반을 선택해요. 자체전은 A·B팀도 선택해요.
  2. 일반 작전판의 자리를 누르거나 스쿼드 한눈에 보기에서 선발·교체·골·도움과 세부 득점을 입력해요.
  3. 입력 창과 전체보기를 닫고 출전 기록 저장 · 집계 확인을 눌러 저장해요. 실제 참석·지각한 선수만 출전시킬 수 있어요.

프리킥·PK는 총 골 안에 포함해요

예: 총 3골 중 직접 프리킥 1골·경기 중 PK 1골이라면 총 골 3 / 프리킥 1 / PK 1로 적어요. 프리킥+PK는 총 골을 넘을 수 없어요. 승부차기는 제외해요.

‘입력 완료’와 ‘입력 완료 · 작전판으로’는 창만 닫아요. 경기 저장을 꼭 눌러 주세요. 교체가 있으면 두 선수는 각 0.5쿼터, 없으면 선발은 1쿼터예요. 교체는 한 자리에 1명까지예요.

09 경기 엑셀 입력

양식 확인 후 초안에 반영

경기 형식과 포메이션을 고른 다음
03에서 그 경기에 맞는 양식을 받아 주세요.

다운로드 → 작성 → 검토

  1. 경기 엑셀 양식 다운로드를 눌러요. 리그는 1~4쿼터, 대회 전·후반은 1·2쿼터 양식이에요.
  2. 쿼터·포지션별 이름·등번호·총 골·도움을 입력해요. 교체 선수는 같은 자리의 교체 행에 적어요.
  3. 업로드 후 오류와 선수 연결을 확인하고 검토한 엑셀로 1~4쿼터 초안 교체 또는 검토한 엑셀로 전·후반 초안 교체를 눌러요.

세부 득점도 확인해요

새 양식 끝의 프리킥·PK는 총 골의 일부예요. 빈칸은 0으로 반영돼요. 세부 열이 없는 예전 양식은 같은 쿼터·선수의 기존 프리킥·PK 값을 유지해요.

초안 반영 뒤 경기 저장이 필요해요

선택한 팀의 전체 구간 배치·골·도움이 파일 내용으로 바뀌고 파일에 없는 구간은 비워져요. 투표·출석·기본 정보·코멘트는 유지돼요.

자체전은 A·B팀별 파일을 사용해요. 실제 출석과 바뀐 내용을 확인한 뒤 출전 기록 저장 · 집계 확인을 눌러요.

파일은 .xlsx · 2MB 이하예요. 전·후반 경기에는 3·4쿼터 행을 넣을 수 없어요. 초안 반영 후 경기 저장을 꼭 눌러 주세요.

완료한 경기에도 수정이 가능해요

11 저장을 이어서

초안 복원과 저장 확인

잠깐 나갔다 돌아와도 작성한 경기를 이어 쓸 수 있어요. 초안 보관과 경기 저장은 달라요.

같은 탭에서 최대 24시간 보관해요

경기 목록의 작성 중인 경기 → 이어서 작성을 눌러요. 새로고침하거나 접속이 만료돼 재로그인했어도 같은 탭·계정·팀이면 복원할 수 있어요.

나갈 때는 보관하고 나가기를 선택해요. 다른 경기를 열려면 보관한 초안을 먼저 저장하거나 버려 주세요.

저장 여부를 확인해 달라고 나오면

목록의 저장 확인 필요 → 초안 열기로 들어가 저장 결과 확인을 눌러요. 확인이 끝나기 전에는 입력을 바꾸거나 새 경기로 다시 등록하지 마세요.

저장이 확인되면 안내에 따라 이어서 작성해요. 계속 실패하면 연결 상태를 확인하고 입력 내용을 보관해 주세요.

필요한 입력은 따로 보관한 뒤 초안 버리기로 정리하고 최신 경기에서 다시 작성해 주세요.

직접 로그아웃하면 초안이 삭제돼요. 탭을 닫거나 다른 기기로 옮기면 복원되지 않을 수 있어요. 보관 실패 경고가 나오면 새로고침하거나 닫지 말고 내용을 따로 보관해 주세요.

12 선수 기록 집계

조회 범위와 정렬

선수 기록에서 팀의 합계와 선수별 기록을 확인해요.
먼저 조회 중인 기간과 경기 구분을 확인해 주세요.

기본 조회는 올해의 완료 기록이에요

올해 · 리그 + 대회 · 자체전 포함 · 기록 완료만 · 용병 제외가 기본이에요. 기간과 경기 구분을 바꾸고, 상세 조건에서 경기 유형·기록 범위·용병 포함을 선택해요.

예전 경기가 빠졌다면 완료 + 이전 기록을 골라 보세요. 작성 중 포함의 합계는 입력이 끝나기 전까지 바뀔 수 있어요.

팀 요약을 읽어요

집계 경기는 매칭·자체전 횟수를 함께 보여요. 누적 득점은 선택 범위의 선수 골을 합산하고, 누적 실점은 외부 팀과의 매칭만 세요.

스코어 미입력은 0실점이 아니에요. 실점에서 제외한 경기 수를 확인해 주세요. 선수 득점 합계는 상대 자책골 등으로 팀 스코어와 다를 수 있어요.

열 제목을 눌러 정렬해요

이름·등번호로 찾고 등번호·선수·득점·도움·FK·PK·출전 경기·출전 쿼터·출석 (회) 제목을 눌러요. 같은 제목을 다시 누르면 오름·내림차순이 바뀌어요. 현재 방향은 ↑↓로 보여요.

‘출석 (회)’는 참석·지각한 경기마다 1회예요. 같은 날 두 경기면 2회이며, 출전하지 않아도 포함해요. 회원은 직책 ‘정회원’만 뜻하지 않으며 용병이 아닌 감독·코치도 포함돼요.

13 개인 기록 확인

경기별 기록까지 확인하기

어떤 경기에서 쌓인 골과 도움인지,
선수 이름이나 등번호를 눌러 확인해 보세요.

목록에서 개인 상세로 이동해요

표 본문의 선수 이름·등번호를 누르면 개인 상세가 열려요. 상세에서도 기간과 리그·대회를 바꿀 수 있고, 시즌 목록으로 돌아가도 최신 조회 조건이 유지돼요.

누적과 쿼터당 기록을 바꿔 봐요

스탯 보기에서 누적 / 1쿼터당 / 2쿼터당 / 3쿼터당 / 4쿼터당을 골라요. 득점·도움·FK·PK에 적용하며 출전·출석은 누적값이에요.

N쿼터당 = 기록 합계 ÷ 실제 출전 쿼터 합계 × N이에요. 출전이 0쿼터면 —로 보여요. 대회 전·후반도 각각 1쿼터이며 분 단위로 환산하지 않아요.

아래 경기 카드는 실제 기록이에요

경기별 기록은 해당 경기의 실제 골·도움 수를 보여요. 프리킥·페널티킥 골이 있을 때만 세부 기록을 덧붙여요. FK·PK는 총 득점에 이미 포함돼요.

원본 경기 보기를 누르면 당시 명단·계획·출전·결과를 조회해요. 이 경로의 원본 화면은 읽기 전용이에요.

원본 연결 화면은 운영진에게도 읽기 전용이에요. 정정하려면 ‘경기 기록’ 메뉴에서 해당 경기를 수정·저장하고 선수 기록을 새로고침해 주세요. 출석률·연말 시상·프로 90분 비교는 별도 정책이에요.

14 팀 · 접속 관리

회원은 팀 코드로 조회하고,
감독·코치는 개인 계정으로 기록을 관리해요.

회원에게 코드 안내하기 · 감독/코치

  1. 팀 · 접속 관리 → 팀 접속 코드 관리를 열어요.
  2. 코드·비밀번호를 발급하고, 표시된 내용을 보관해요.
  3. 팀원에게 코드와 6자리 비밀번호를 함께 안내해요. 사용 가이드 → PDF 내려받기로 안내서도 받을 수 있어요.

유효기간은 90일이에요. 원문은 발급 직후 한 번만 보여요. 재발급하면 기존 코드·비밀번호와 회원 접속이 종료돼요.

코치 임명하기 · 감독

팀 · 접속 관리 → 코치 관리에서 기존 계정의 정확한 로그인 아이디를 입력하고 코치 임명을 눌러요.

계정이 없다면 코치 초대 만들기로 24시간 일회용 링크를 발급해 당사자에게 전달해요.

권한을 해제하려면 조회 회원으로 변경을 눌러요. 기존 경기 기록은 유지돼요. 감독 권한 변경은 서비스관리자에게 요청해 주세요.

선수 직책과 로그인 권한은 별개예요. 회원에게는 회원용 가이드를 전달해 주세요. 비밀번호·팀 코드·초대 링크는 가이드에 넣지 말고 대상자에게 별도로 안내해 주세요.
