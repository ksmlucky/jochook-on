01 운영진 접속

우리 팀 기록 관리하기

경기 전에는 명단과 계획을,
경기 후에는 실제 출전과 결과를 남겨요.

조축ON 열기 →

개인 계정으로 로그인해요

  1. 접속 화면에서 운영진 로그인을 눌러요.
  2. 개인 아이디·비밀번호로 로그인해요.
  3. 현재 팀과 감독·코치 권한을 확인해요. 여러 팀에 속했다면 팀 · 접속 관리 → 내 팀 목록에서 선택해요.

처음 초대받았다면

초대 링크에서 팀과 권한을 확인한 뒤, 아이디와 12자 이상 비밀번호를 정하고 계정 설정 · 팀 참여를 눌러요. 이미 계정이 있으면 기존 계정으로 로그인하고 수락해요.

초대는 24시간 동안 한 번 사용할 수 있어요. 만료됐거나 비밀번호를 잊었다면 초대해 준 관리자에게 문의해 주세요.

감독·코치는 선수와 경기 기록을 관리해요. 감독은 코치도 임명할 수 있어요. 선수 명단의 직책만 바꿔서는 로그인 권한이 생기지 않아요.

02 경기 전에

선수단 준비하기

선수를 먼저 등록하면 경기마다 명단에서 편하게 선택할 수 있어요.

한 명 등록하거나 수정하기

  1. 선수단 → 선수 등록을 눌러요. 기존 선수는 카드·표의 수정을 눌러요.
  2. 이름·기본 포지션·1지망을 입력해요. 포지션을 모르면 기본 포지션을 미확인으로 두고 지망을 비워요.
  3. 등번호·생년·직책·가입일과 2·3지망을 확인한 뒤 선수 등록하기 또는 변경 사항 저장을 눌러요.

입력 기준

등번호는 1~99이며 활동 선수끼리 중복할 수 없어요. 번호·생년을 모르면 비워 두세요. 생년은 4자리 입력 또는 목록 선택이 가능해요.

2·3지망은 선택이고 같은 포지션을 중복 선택할 수 없어요. 직책은 정회원·코치·감독·총무·회장 중 하나예요.

여러 명 한 번에 등록하기

여러 명 입력으로 행을 추가하거나 엑셀 업로드에서 양식을 받아 작성해요. 검토 오류를 고친 뒤 ○명 전체 등록을 눌러야 저장돼요.

최대 200명 · .xlsx · 2MB 이하. 일괄 등록은 새 선수 추가용이에요.

연령대는 생일과 관계없이 연도에서 생년을 뺀 기준이에요. 예: 2026년 - 1996년 = 30세, 30대.

03 경기 입력 · 01단계

투표와 실제 출석

경기 기록 → 경기 기록 등록에서 시작해요.
카카오톡 투표를 직접 옮겨 적는 방식이에요.

기본 정보부터 입력해요

외부 경기 또는 자체전 · A팀 vs B팀을 선택해요. 유형은 하루 4쿼터 전체에 적용되고, 배치·스코어 입력 후 또는 저장 후에는 바꿀 수 없어요.

날짜와 시작 시간은 필수예요. 시·분을 따로 선택하며 분은 00·30만 가능해요. 11:00을 입력하면 11:00-13:00으로 보여요. 상대 팀과 장소는 선택이에요.

참석 예정 명단을 골라요

이름·등번호로 검색하고 참석에 투표한 선수 카드를 선택해요. 선택한 선수만 보기로 빠진 사람을 확인해 주세요. 선택을 해제하면 미투표로 돌아가요.

실제 출석은 따로 확인해요

투표 상세·실제 출석 입력 펼치기에서 불참 예정·미정 투표와 실제 참석·지각·불참·미확인을 입력해요.

투표 저장 · 스쿼드 계획으로를 누르면 현재 입력 내용을 저장하고 02로 이동해요.

참석 투표만으로 실제 출석이 되지는 않아요. 오늘은 여기까지라면 ‘중간 저장 · 목록으로’를 누르고, 다음에 ‘이어서 작성’으로 열어요.

04 스쿼드 준비

포메이션 선택하기

경기 기본 정보 아래에서 포메이션을 고르고
참석 인원에 맞춰 스쿼드를 짜요.

6가지 구성 중에서 선택해요

4-1-2-3 · 기본 구성, 수비형 미드필더 1명
4-4-2 · 수비·미드필더 두 줄과 공격수 2명
4-2-3-1 · 수비형 미드필더 2명과 공격형 1명
4-1-4-1 · 수비형 1명과 미드필더 4명
3-5-2 · 중앙 수비수 3명, 윙백과 공격수 2명
3-4-3 · 중앙 수비수 3명, 윙백과 공격수 3명

같은 팀은 네 쿼터에 함께 적용해요

선택한 포메이션을 02 계획과 03 실제 출전에 함께 써요. 쿼터별로 다르게 정하는 방식은 아니에요. 자체전은 A팀과 B팀을 각각 선택해요.

선호 포지션에는 LM·RM·CAM·LWB·RWB도 선택할 수 있어요. 중앙 수비/미드필더의 좌우 자리는 CB·CM·CDM 지망으로 연결돼요.

이미 배치했다면 변경 내용을 확인해요

계획이 있으면 확인창이 나와요. 공통 자리의 선수는 유지하고, 새 포메이션에 없는 자리의 계획 배치는 해제해요. 선수는 참석 명단에 남아요.

해당 팀에 실제 출전 기록이 있으면 변경이 잠겨요. 꼭 바꿔야 한다면 03의 출전·골·도움을 확인하고 직접 배치를 해제한 뒤 변경해요.

한눈에 보기의 3-5-2는 넓은 화면에서 미드필더 5명을 한 줄로, 좁은 화면에서는 겹치지 않도록 나눠 보여 줘요. 선수가 빠지거나 포메이션이 바뀌는 것은 아니에요.

05 경기 입력 · 02단계

4쿼터 스쿼드 계획

선택한 포메이션으로 네 쿼터를 준비해요.
배치와 출전량을 확인한 뒤 계획을 저장해 주세요.

자동 편성으로 시작하기

외부 경기에서 명단을 확인하고 1~4쿼터 자동 편성을 눌러요. 선호 포지션·출전 배분·과거 출석률을 고려해요. GK 지망이 있는 선수는 GK 그룹으로 분류돼요.

모두 네 쿼터에 참여할 수 있을 때 사용하고, 경고와 선수별 배분을 확인해 주세요.

배치·교체를 직접 바꾸기

  1. 쿼터를 고르고 선수 카드를 누른 뒤 자리를 눌러요. 스쿼드 한눈에 보기에서는 자리를 눌러 선발·교체를 바로 고를 수 있어요.
  2. 일반 화면은 선수 카드를 고른 뒤 + 교체를 눌러요. 한눈에 보기에서는 해당 자리의 교체 선수를 골라요.
  3. 다른 쿼터도 확인해요. 같게 쓰려면 이전 쿼터 계획 복사를 이용해요.

용병·자체전도 기록해요

+ 용병 추가에서 기존 용병을 고르거나 등록해요. 이름은 필수, 등번호는 선택이에요. 용병 정보는 즉시 저장되고 참가·배치는 경기 저장 때 반영돼요.

자체전은 A·B팀을 각각 직접 배치해요. 같은 쿼터에 한 선수를 양 팀에 넣을 수 없고, 자동 편성은 제공하지 않아요.

한눈에 보기의 ‘입력 완료 · 작전판으로’는 창을 닫아요. 전체보기를 닫고 ‘계획 저장 · 실제 기록으로’를 눌러야 저장돼요. 계획은 실제 출전 집계와 별개예요.

06 경기 입력 · 03단계

실제 출전·골·도움

계획대로 뛰었다면 복사하고,
달라진 선수와 기록만 고쳐 주세요.

계획대로 뛰었다면

02 계획대로 참석·출전 기록 저장을 누르면 계획을 실제 출전으로 복사하고 현재 입력 내용 전체를 저장해요. 참석 예정자의 미확인 출석은 참석으로 바뀌고, 골·도움은 0부터 시작해요.

지각·불참은 유지돼요. 불참 선수가 계획에 있으면 먼저 정정해 주세요. 이미 실제 출전 기록이 있으면 일괄 복사는 할 수 없어요.

휴대폰에서 기록 고치기

  1. 쿼터를 선택해요. 자체전은 A·B팀도 선택해요.
  2. 일반 작전판의 자리를 누르거나 스쿼드 한눈에 보기에서 자리를 눌러 선발·교체·골·도움을 입력해요.
  3. 입력 창과 전체보기를 닫고 출전 기록 저장 · 집계 확인을 눌러 저장해요. 실제 참석·지각한 선수만 출전시킬 수 있어요.

엑셀로 입력할 때

경기 엑셀 양식 다운로드 → 작성 → 업로드 → 검토 → 검토한 엑셀로 4쿼터 초안 교체 순서예요.

선택한 팀의 4쿼터 배치·골·도움 전체가 바뀌고 파일에 없는 쿼터는 비워져요. 자체전은 팀별 파일을 사용해요. 실제 출석을 확인한 뒤 경기 저장을 눌러 주세요.

‘입력 완료’와 ‘입력 완료 · 작전판으로’는 창만 닫아요. 경기 저장을 꼭 눌러 주세요. 교체가 있으면 두 선수는 각 0.5쿼터, 없으면 선발은 1쿼터예요. 교체는 한 자리에 1명까지예요.

07 경기 입력 · 04단계

완료·수정·변경 이력

선수별 합계와 스코어를 확인하고
기록 완료로 표시해 주세요.

경기를 마무리해요

  1. 4쿼터 합계 스코어를 입력해요. 외부 경기는 우리 팀:상대 팀, 자체전은 A팀:B팀이에요.
  2. 코멘트를 남기고 선수별 실제 기록을 대조해요.
  3. 기록 완료 · 목록으로를 눌러요. 빈 항목이 있어도 완료할 수 있으니 먼저 확인해 주세요.

스코어와 선수 득점 합계가 다르면 안내가 나와요. 득점자 미확인·자책골 등을 확인한 뒤 그대로 저장할 수도 있어요.

완료한 경기에도 수정이 가능해요

감독·코치는 완료 후에도 수정할 수 있어요. 중간 저장하면 다시 작성 중으로 바뀌어요.

변경 이력에서 작업자·변경 시간·전후 내용을 확인해요. 투표·실제 출석·배치·골·도움도 남고, 시간은 한국 기준이에요.

삭제는 경기 전체에 적용돼요

목록의 삭제를 누르면 확인창이 나와요. 선수 명단과 변경 이력은 남지만, 삭제한 경기를 되돌리는 버튼은 없어요.

탭 이동이나 초안 보관은 경기 저장과 달라요. 저장 성공 안내를 확인해 주세요. 저장 결과가 불확실하거나 다른 운영진의 수정과 겹치면 다음 쪽의 복구 안내를 따라 주세요.

08 저장을 이어서

초안 복원과 저장 확인

잠깐 나갔다 돌아와도 작성한 경기를 이어 쓸 수 있어요. 초안 보관과 경기 저장은 달라요.

같은 탭에서 최대 24시간 보관해요

경기 목록의 작성 중인 경기 → 이어서 작성을 눌러요. 새로고침하거나 접속이 만료돼 재로그인했어도 같은 탭·계정·팀이면 복원할 수 있어요.

나갈 때는 보관하고 나가기를 선택해요. 다른 경기를 열려면 보관한 초안을 먼저 저장하거나 버려 주세요.

저장 여부를 확인해 달라고 나오면

목록의 저장 확인 필요 → 초안 열기로 들어가 저장 결과 확인을 눌러요. 확인이 끝나기 전에는 입력을 바꾸거나 새 경기로 다시 등록하지 마세요.

저장이 확인되면 안내에 따라 이어서 작성해요. 계속 실패하면 연결 상태를 확인하고 입력 내용을 보관해 주세요.

다른 운영진이 먼저 수정했다면

최신 기록 보기로 최근 저장된 내용을 확인해요. 기존 초안과 자동으로 합치거나 덮어쓰지 않아요.

필요한 입력은 따로 보관한 뒤 초안 버리기로 정리하고 최신 경기에서 다시 작성해 주세요.

직접 로그아웃하면 초안이 삭제돼요. 탭을 닫거나 다른 기기로 옮기면 복원되지 않을 수 있어요. 보관 실패 경고가 나오면 새로고침하거나 닫지 말고 내용을 따로 보관해 주세요.

09 시즌 기록 확인

선수 기록 집계하기

경기를 정리한 뒤 선수 기록에서 합계를 확인해요. 회원에게도 같은 집계 기준으로 보여요.

먼저 집계 범위를 확인해요

기본은 올해 · 외부 경기 · 기록 완료만 · 용병 제외예요. 시즌·경기 유형·기록 범위를 바꾸거나 용병 포함을 선택할 수 있어요.

예전 경기가 빠져 있다면 완료 + 이전 기록을 골라 보세요. 작성 중 포함의 합계는 입력이 끝나기 전까지 바뀔 수 있어요.

보고 싶은 선수와 기록 찾기

회원에게 코드 안내하기 · 감독/코치

  1. 팀 · 접속 관리 → 팀 접속 코드 관리를 열어요.
  2. 코드·비밀번호를 발급하고, 표시된 내용을 보관해요.
  3. 팀원에게 코드와 6자리 비밀번호를 함께 안내해요. 사용 가이드 → PDF 내려받기로 안내서도 받을 수 있어요.

유효기간은 90일이에요. 원문은 발급 직후 한 번만 보여요. 재발급하면 기존 코드·비밀번호와 회원 접속이 종료돼요.

코치 임명하기 · 감독

팀 · 접속 관리 → 코치 관리에서 기존 계정의 정확한 로그인 아이디를 입력하고 코치 임명을 눌러요.

계정이 없다면 코치 초대 만들기로 24시간 일회용 링크를 발급해 당사자에게 전달해요.

권한을 해제하려면 조회 회원으로 변경을 눌러요. 기존 경기 기록은 유지돼요. 감독 권한 변경은 서비스관리자에게 요청해 주세요.

선수 직책과 로그인 권한은 별개예요. 회원에게는 회원용 가이드를 전달해 주세요. 비밀번호·팀 코드·초대 링크는 가이드에 넣지 말고 대상자에게 별도로 안내해 주세요.
