## 범위와 화면 흐름

01 참석 명단 → 02 스쿼드 배치 → 03 골별 기록·결과·코멘트.

- 02 선발 자리를 누르면 이름순 선수 목록과 선발 해제만 표시한다. 검색·닫기·오류 안내는 유지한다. 선수 선택/해제 성공 시 즉시 초안 반영 후 창이 닫힌다.
- 선발이 있는 자리만 + 교체가 보인다. 교체를 누르면 같은 구조의 교체 전용 선택창이 열린다. 한눈에 보기에서도 교체 버튼을 별도로 제공한다.
- 작전판의 배치·기록 보조 버튼과 골·도움 입력을 제거한다. 선수·교체는 02, 골·도움·FK/PK는 03에서 입력한다.
- 경기 엑셀 UI 및 MatchEditor 연결을 제거한다. 선수 등록 엑셀 기능은 유지한다. 기존 서버 호환 API나 DB는 변경하지 않는다.
- 03에서 경기 형식에 따라 1~4쿼터 또는 전·후반을 선택한다. 자체전은 A/B팀을 선택한다. 해당 구간 출전 선수만 득점자·도움 후보이다.
- 구간별 기록 저장은 경기 전체 초안을 기존 버전/저장 영수증 방식으로 원자적으로 저장한다. 다른 수정도 함께 저장됨을 버튼 아래 명시한다. 저장 후 같은 쿼터와 스크롤을 유지하며 RESULT 상태이다. 경기 완료는 별도이다.
- 기존 합계 방식 경기의 정정 기능은 03의 접힌 ‘기존 선수별 골·도움 수정’에 유지한다. 골별 연결을 완료한 구간은 골별 기록에서만 수정한다.
- 고정 버튼은 최대160px, 버튼 높이44px. 중간 단계 ‘목록 / 다음’, 최종 단계 ‘목록 / 완료’. 모두 기존 저장 동작을 유지하고 접근성 이름으로 저장·이동 의미를 제공한다.
