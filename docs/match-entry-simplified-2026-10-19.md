# 경기 배치와 골 기록 분리 (로컬 개발판)

2026-10-19. 미배포. 운영 웹은 be49b2f / API dd29444 / DB V31 / 가이드1.10을 유지한다.

## 범위와 화면 흐름

01 참석 명단 → 02 스쿼드 배치 → 03 골별 기록·결과·코멘트.

- 02 선발 자리를 누르면 이름순 선수 목록과 선발 해제만 표시한다. 검색·닫기·오류 안내는 유지한다. 선수 선택/해제 성공 시 즉시 초안 반영 후 창이 닫힌다.
- 선발이 있는 자리만 + 교체가 보인다. 교체를 누르면 같은 구조의 교체 전용 선택창이 열린다. 한눈에 보기에서도 교체 버튼을 별도로 제공한다.
- 작전판의 배치·기록 보조 버튼과 골·도움 입력을 제거한다. 선수·교체는 02, 골·도움·FK/PK는 03에서 입력한다.
- 경기 엑셀 UI 및 MatchEditor 연결을 제거한다. 선수 등록 엑셀 기능은 유지한다. 기존 서버 호환 API나 DB는 변경하지 않는다.
- 03에서 경기 형식에 따라 1~4쿼터 또는 전·후반을 선택한다. 자체전은 A/B팀을 선택한다. 해당 구간 출전 선수만 득점자·도움 후보이다.
- 구간별 기록 저장은 경기 전체 초안을 기존 버전/저장 영수증 방식으로 원자적으로 저장한다. 다른 수정도 함께 저장됨을 버튼 아래 명시한다. 저장 후 같은 쿼터와 스크롤을 유지하며 RESULT 상태이다. 경기 완료는 별도이다.
- 기존 합계 방식 경기의 정정 기능은 03의 접힌 ‘기존 선수별 골·도움 수정’에 유지한다. 골별 연결을 완료한 구간은 골별 기록에서만 수정한다.
- 고정 버튼은 최대160px, 버튼 높이44px. 중간 단계 ‘목록 / 다음’, 최종 단계 ‘목록 / 완료’. 모두 기존 저장 동작을 유지하고 접근성 이름으로 저장·이동 의미를 제공한다.

## 예외와 검증

골 기록이 있는 선수의 배치 제거 차단, 자체전 팀 분리, 세션 만료·저장 응답 유실·충돌 시 기존 초안 보존을 유지한다. 신규 quarter-1~4 저장 목적지를 복원 허용 목록에 추가하고 정확한 재시도 본문·쿼터 보존 테스트를 추가했다.

프론트 테스트278개·타입검사·production build 통과. 가상 모바일390px에서 선택창 필드 축소, 선발 해제 후 교체 숨김, 선발 재배치 후 교체 선택·닫기, 03 2쿼터 골/도움 추가·저장·화면 유지 확인. 실제 iPhone·운영 자료 쓰기·로컬 MySQL 통합은 미실행. API/DB 변경 없음.

## 가이드 반영 계획 (배포 전)

운영용 1.10은 배포 기준으로 보존한다. 다음 기능 배포를 준비할 때 공통 content.json과 PDF/HTML을 함께 1.11로 갱신한다.

- 운영진: 스쿼드 배치와 교체(현재9쪽)는 간단 선택창·독립 교체 버튼으로 수정. 골별 기록(현재10쪽)·기존 합계 연결(현재11쪽)은 03으로 이동. 경기 엑셀(현재12쪽)은 제거. 완료·초안 복원 설명은 구간별 저장과 ‘목록/다음/완료’ 명칭으로 수정.
- 회원: 경기 조회(현재3쪽), 기록 읽기(현재7쪽)의 골별 기록 위치를 03으로 수정. 선수 등록 엑셀 및 시즌 집계 정책은 변경 없음.
- 배포 준비 때 전체 PDF 페이지를 재생성·렌더 검토하고 앱 목차·PDF 링크를 확인한다. 미배포 동작을 운영 사용법으로 안내하지 않는다.
