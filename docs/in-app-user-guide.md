## 범위와 화면 흐름

접속한 팀에서 상단 **사용 가이드**를 누르면 현재 로그인 권한에 맞는 설명을 바로 연다.

| 접속 상태 | 열리는 가이드 |
| --- | --- |
| 활성 팀의 감독·코치 개인 계정 | 운영진용 17개 항목 |
| 회원 계정·팀 코드 조회 접속 | 회원용 7개 항목 |
| 서비스 관리자이지만 현재 팀 감독·코치가 아닌 계정 | 회원용 |
| 로그인 전 또는 팀 미선택 | 기존 접속·팀 선택 흐름 먼저 진행 |

선수 직책이 아닌 기존 `canEditTeam` 권한을 기준으로 한다. 가이드 표시는 읽기 안내이며 서버 수정 권한을 바꾸지 않는다.

1. 상단 **사용 가이드**를 누른다. 편집 중이면 기존 초안 보호·이동 확인을 거친다.
2. 역할과 가이드 버전·기능판을 확인한다.
3. PC는 왼쪽 목차, 휴대폰은 선택 목차로 한 항목씩 읽는다. 아래 이전·다음으로도 이동하며 제목에 포커스와 스크롤을 옮긴다.
4. **PDF 내려받기**로 같은 역할의 공유본을 받는다. 공개 접속 주소는 새 탭으로 열린다.
5. `#guide` 직접 접속·새로고침도 같은 권한 판정을 사용한다. 역할이 바뀌면 이전 역할의 장을 남기지 않는다.

![가상 검증팀의 모바일 운영진 가이드](diagrams/in-app-user-guide-mobile.png)

위 그림은 최초 구현 시점의 가상 계정 화면으로 이전 항목 수를 보여 준다. 현재 1.3의 목차·본문은 공통 원본과 역할별 HTML/PDF를 따른다. 실제 회원 정보나 접속 비밀값은 포함하지 않는다.

## 가이드 1.3에 포함한 사용법

- 새 홈, 모바일 간단/표 보기와 접힌 필터, 내 비밀번호 변경, 서비스 관리자의 본인 확인 후 30분 일회용 운영진 복구 링크 절차.

- 공통: 기간 범위·올해/전체 기간, 리그(자체전 포함)·대회별 조회, 팀 요약과 열 제목 정렬, 선수별 상세·읽기 전용 원본 연결, 누적/1~4쿼터당 기록과 FK·PK 부분합.
- 운영진: 대회 등록·수정·경기 연결, 생년·가용 등번호 입력/목록, 자체전 01 A/B 체크와 02 팀별 편성, 352/343 배치, 대회 전·후반 각30분·교체0.5, 형식별 엑셀과 04 완료 전 확인.
- 기존 접속·권한·초안 복원·저장 결과 확인은 유지한다. 시상 정책·프로 선수 비교·대회 삭제·승부차기를 지원 기능으로 안내하지 않는다.

## 원본과 빌드

- `docs/guides/content.json`을 React와 HTML/PDF 생성기가 함께 사용한다. 화면용 원고를 별도로 복사하지 않는다.
- React는 `<b>`와 `<br/>`만 해석하고 나머지는 텍스트로 처리한다. HTML 직접 삽입은 사용하지 않는다.
- 역할별 PDF를 `?url` 정적 import로 빌드에 넣고 파일 변경 시 새 자산 이름을 사용한다. Docker 프론트 빌드에는 공통 JSON과 두 PDF를 포함한다.
- 현재 원고는 회원용7쪽·운영진용17쪽이다. [가이드 모음](guides/index.html)과 [유지관리 기록](guides/maintenance.json)에 버전·기능·운영 상태를 남긴다.
- 배포 전 원고·PDF를 기능과 함께 준비하고, 실제 운영 검증 뒤 `scope`·`appCommit`과 상태만 확정한다. 본문·releaseLabel이 같으면 PDF·HTML을 다시 생성하지 않는다. 문서 확정 커밋은 운영 앱 커밋과 구분한다.

## 검증과 남은 확인

- PDF 전20쪽을 PNG로 렌더해 한글·여백·제목·페이지 번호·잘림을 확인했다. 제목·푸터·공개 주소 링크·HTML 항목 수·`outputs/` 사본 바이트 일치도 통과했다.
- 현재 소스의 메뉴·버튼·기간·권한·계산·팀 선택·저장 순서와 원고를 대조했다.
- 총괄의 로컬 UI 확인: 운영진14개 목차·01 자체전 안내·PDF 연결, 별도 회원 모의 응답의6개 목차·대회 규칙·회원 PDF 연결을 확인했다. 실제 회원 코드로 운영 접속을 검증한 것과는 구분한다.
- 총괄이 같은 커밋의 API·웹 배포 완료와 운영 CDN의 JS/CSS·회원용/운영진용 PDF 바이트 일치를 확인했다. 실제 iPhone Safari에서 이번 가이드 조작은 사용자 확인 대상으로 남긴다.
