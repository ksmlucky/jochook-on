# 앱 안의 사용자 가이드

**2026-10-21 21:19:06 KST · 가이드 1.20 운영 반영 / 웹 a05b872.** 원형 등번호·이름·연령대 및 골별 득점·도움 공유 안내. 역할별 앱 화면과 PDF 연결 확인.

## 역할과 화면 흐름

| 접속 상태 | 열리는 가이드 |
| --- | --- |
| 활성 팀의 감독·코치 개인 계정 | 운영진용 6개 항목·PDF 6쪽 |
| 회원 계정·팀 코드 접속 | 회원용 3개 항목·PDF 3쪽 |
| 서비스 관리자이지만 현재 팀 감독·코치가 아닌 계정 | 회원용 |
| 로그인 전 또는 팀 미선택 | 기존 접속·팀 선택 흐름 먼저 진행 |

선수 명단의 직책이 아닌 `canEditTeam` 권한으로 구분한다. 가이드 열람이 수정 권한을 바꾸지는 않는다.

1. **사용 가이드** 메뉴를 연다. 편집 중이면 기존 초안 보호·이동 확인을 거친다.
2. 역할·버전을 확인하고 목차 또는 이전·다음으로 필요한 항목을 읽는다.
3. **PDF 내려받기**로 같은 역할의 공유본을 받는다.

PC는 왼쪽 목차, 휴대폰은 선택 목차를 사용한다. `#guide` 직접 접속도 같은 권한을 적용하며 역할이 바뀌면 이전 역할의 장을 남기지 않는다.

## 원본과 배포 관리

- React와 HTML/PDF 생성기는 `docs/guides/content.json`을 함께 사용한다. React는 `<b>`·`<br/>`만 해석한다.
- 역할별 PDF는 `?url` 정적 import로 웹 빌드에 포함한다. 내용 변경 시 새 자산 이름으로 배포한다.
- `scripts/Generate-UserGuides.py`가 HTML·PDF와 `outputs/` 전달용 PDF 사본을 만든다.
- 배포 전 `scope=pending_deployment`와 pending 커밋 식별자를 사용한다. 배포 확인 후 실제 커밋·운영 상태를 확정한다. 본문·기능판 이름이 그대로면 PDF를 다시 만들지 않는다.
- 버전별 변경 내용·검증·운영 반영 여부는 [유지관리 기록](guides/maintenance.json)에 보존한다. 문서 업로드와 앱 배포는 별도다.

## 검증

회원 3쪽·운영진 6쪽 총 9쪽을 Poppler 100dpi PNG로 렌더해 모두 확인했다. 한글·여백·쪽번호가 정상이고 잘림·겹침이 없다. 생성기 글꼴·페이지 넘침 검사와 pypdf 페이지수·텍스트 검사, `outputs/` 사본 SHA256 비교를 통과했다.

`MatchReport`·`MatchResultImageShare`·`matchResultImage` 소스로 표시·공유 버튼을 대조했다. 경기 조회 흐름도도 SVG/PNG를 생성해 확인했다. 총괄이 가상 회원 3개·운영진 6개 목차와 가이드1.20·새 문구·각 PDF 연결을 확인했다. 운영 배포·공개 PDF 일치는 배포 후 확정하며 실제 iPhone 조작은 사용자 확인으로 남긴다. 가이드와 그림에는 가상 예시만 사용한다.
