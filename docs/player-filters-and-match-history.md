# 선수 필터와 경기 변경 이력

2026-10-14: 사용자는 감독·코치의 직접 수정 권한을 유지하고 변경 이력으로 관리하는 방식을 선택했다. 감독 승인 절차는 이번 범위에 포함하지 않는다.

## 선수단 필터

- 연령대·직책·1지망 포지션 각각 하나씩 선택하며 세 조건은 AND로 적용한다. 기본은 모두 전체이다.
- 연령대는 한국의 현재 연도 − 생년이다. 20세 미만, 20~90대, 100세 이상, 생년 미확인 중 **현재 팀의 전체 활동 회원에 실제 존재하는 항목만** 제공한다. 페이지·다른 필터와 무관하게 선택지를 유지하며 생년 미확인도 해당 회원이 있을 때만 표시한다. 예를 들어 2026년에는 1996년생이 30대에 포함된다.
- 직책은 정회원·코치·감독·총무·회장, 포지션은 **공격(LW/ST/RW)·미드(CM/CDM)·수비(LB/CB/RB)·키퍼(GK)**이다. 포지션 그룹은 1지망만 기준으로 하며 미입력 선수는 전체 조회에 포함한다. 직책 필터는 선수 소개 정보이며 개인 로그인 권한을 검색하는 것이 아니다.
- 전체 활동 회원을 DB에서 필터링한 뒤 기존 정렬과 페이지 크기를 적용한다. 용병 선택과 경기 참가자 선택에는 선수단 화면 필터를 전파하지 않는다.
- 화면: 선수단 → 세 필터 선택 → 결과 인원과 카드/표 갱신. 변경하면 첫 페이지로 이동하고, 초기화는 정렬·페이지 크기를 유지한다. 0명이면 조건 변경/초기화를 안내한다.

## 경기 변경 이력

- 감독·코치 개인 계정만 등록·수정·삭제할 수 있고 해당 팀의 이력을 조회할 수 있다. 팀 코드 회원·조회 회원은 이력을 볼 수 없다.
- 경기 전체 저장 시 등록(CREATED)·수정(UPDATED), 삭제 시 삭제(DELETED) 이력을 추가한다. 단계별 저장도 각각의 저장 행위로 기록한다.
- 작업자의 서버 인증 계정 ID·당시 로그인 아이디, 작업 시간, 경기 ID·날짜·유형·상대팀, 전후 버전, 전후 전체 기록을 보관한다. 클라이언트가 작업자나 시간을 지정할 수 없다.
- 경기 변경과 이력 INSERT는 같은 트랜잭션이다. 권한 오류·버전 충돌·검증 실패에는 이력을 만들지 않고, 이력 저장 실패 시 경기 변경도 롤백한다.
- 삭제한 경기의 원본 행·참가·쿼터·스쿼드는 경기 집계에서 제거하지만 감사용 전후 내용은 유지한다. 이력 수정·삭제·복구 API는 제공하지 않는다. DB 관리자까지 차단하는 위변조 방지 시스템은 아니다.
- 기존 경기의 알 수 없는 과거 작업자·시간은 만들어 넣지 않는다. 기능 적용 이후 최초 변경부터 기록하고 그 변경 직전 내용은 before_snapshot에 남긴다.
- 화면: 경기 기록 → **변경 이력** → 최근 10개 이력 → **변경 내용 보기** → 기본 정보·스코어·코멘트·투표/출석·쿼터 배치/득점/도움을 전후 비교한다. 선수는 당시 등번호·이름으로 표시한다. 목록에 작업자와 **변경 일시 · 한국 시간**을 구분해 표시하며 시각은 `YYYY-MM-DD HH:mm:ss` 형식이다. 경기 날짜와 변경 날짜는 별개다.

## 테이블과 API

V19 `match_record_events`는 `team_id`, `match_id`, `actor_account_id`, `actor_username`, `action`, `occurred_at`(UTC), `played_on`, `match_kind`, `opponent`, `before_version`, `after_version`, `before_snapshot`(JSON), `after_snapshot`(JSON)을 저장한다. 팀+시각, 팀+경기+시각 인덱스를 둔다. 삭제 후에도 보관하기 위해 경기/선수/계정 FK로 원본 행의 생존을 강제하지 않는다.

`GET /api/v1/players`의 화면 선택 조건은 `ageGroup`, `clubRole`, `positionGroup=FW|MF|DF|GK`이다. 기존 `firstChoice` 조건도 API 호환성을 유지하며 함께 지정하면 AND이다. 생략·빈 값은 전체, 잘못된 값은 400이다. 응답의 `availableAgeGroups`는 현재 팀 활동 회원 전체에 존재하는 연령대 코드의 오름차순 목록이며 UNKNOWN은 마지막이다. 선수 수정으로 선택 중인 연령대가 없어지면 해당 연령 필터를 전체로 되돌린다.

`GET /api/v1/matches/history?page=0&size=10`은 `{items,page,totalPages,totalElements}`를 반환하며 선택적으로 `matchId`를 받는다. 각 항목은 `{id,matchId,action,actorUsername,occurredAt,playedOn,kind,opponent,beforeVersion,afterVersion}`이다. `GET /api/v1/matches/history/{eventId}`는 같은 정보에 `before`, `after` 전체 경기 응답을 추가한다. 팀 범위와 감독·코치 권한을 서버에서 확인하며 다른 팀 이력은 404이다.

인수 기준은 필터 경계/미확인/조합/전체 건수·페이지 정확성, 팀 격리, 감독·코치와 회원 권한, 변경 전후 내용·서버 작업자·UTC 시각, 삭제 후 이력 보존, 이력 실패 시 경기 전체 롤백이다. 실제 실행한 결과는 [검증 기록](verification.md)을 따른다.
