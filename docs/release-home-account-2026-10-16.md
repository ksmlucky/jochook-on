## 휴대폰에서 확인할 것

1. 기존 앱을 새로고침한다. 로그인 화면이 나오면 기존 계정 또는 팀 코드로 다시 접속한다.
2. 새 홈에서 최근 경기와 선수 기록을 열어 본다. 운영진은 작성 중인 경기를 이어서 열어 본다.
3. 선수 기록의 간단 보기·표와 접힌 조회 조건이 편한지 확인한다.
4. 사용 가이드1.3과 PDF 내려받기를 확인한다.

실제 아이폰 실기기 조작은 사용자가 확인할 범위다. 실제 운영 계정의 비밀번호 변경·재설정 링크 발급/사용은 시험하지 않았으며 자동/통합 검증과 구분한다.

## 운영 경계와 복구

- 재시작으로 기존 메모리 세션이 종료될 수 있다. 기존 계정·팀 코드·비밀번호는 보존했다.
- 자동 daily 백업과 PC 밖 독립 사본은 여전히 미설정이다. 이번 사본은 수동 배포 전 백업이며 DPAPI는 현재 Windows 사용자에 종속된다.
- 장애 시 새 쓰기를 멈추고 현재 DB도 보존한 뒤 원인을 확인한다. V26 자리 변경 및 V29 인증 버전 정책 때문에 구 API 이미지만 무심코 롤백하지 않는다. 수정 배포를 우선 검토하고, 백업 복원은 복구 시점 이후 입력 손실을 확인한 뒤 별도로 결정한다.
- 가이드의 본문/HTML/PDF는 배포 전에 고정했다. 배포 후 `content.json`의 scope/appCommit 및 maintenance의 운영 확인 메타데이터만 확정한 문서 커밋은 운영 이미지 커밋과 구분한다.
