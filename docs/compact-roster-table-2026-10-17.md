# 선수단 표와 선택형 일괄 입력 (운영 반영 완료)

## 화면 흐름과 기준
- 선수단 → 표 보기: 번호 / 선수(이름·직책) / 나이(연도 기준 나이·연령대·생년) / 선호 포지션(1·2·3지망) / 가입일 / 관리. 조회 회원은 관리 열 없음.
- 표 최소 폭 960 → 540px, 최대 900px. 셀 여백 축소, 모바일 행 약 50px. 긴 이름 줄바꿈, 모바일 가로 스크롤 시 이름 열 고정. 모든 기존 값·페이지·정렬·수정 기능 유지.
- 여러 명 입력 → 등번호·생년 드롭다운 → 행 추가 → 검토 → 전체 등록. 등번호는 팀 내 남는 1~99번, 생년은 1950~한국 기준 현재 연도-17. 모르면 미등록/미확인 선택.
- 고른 등번호는 다른 입력 행에서 제외되고 해당 행 삭제·선택 해제 시 반환된다. 번호 조회 실패 시 재조회 안내와 버튼, 번호 없는 등록은 가능.
- 단일 등록과 엑셀 검토는 기존 직접 입력을 유지하여 엑셀의 잘못된 값이나 목록 밖 기존 생년을 수정할 수 있다. API·DB 검증·권한 변경 없음.
