## 아직 실행하지 못한 항목

- Docker 런타임이 없어 `docker compose up`과 Testcontainers의 `integrationTest`는 실행하지 못했습니다.
- 따라서 실제 MySQL에서 Flyway 마이그레이션 → JPA 매핑 → API 응답까지 연결되는 과정은 확인이 남아 있습니다.
- GitHub Actions는 작업 정의만 작성했습니다. GitHub에서 실행한 결과는 아직 없습니다.

## 이 작업 환경의 프론트엔드 실행 제한

일반 `pnpm build`의 타입 검사는 통과했으나, Vite가 Windows 네트워크 드라이브를 확인하기 위해 실행하는 `net use`에서 작업 환경의 `spawn EPERM` 제한이 발생했습니다.

프로젝트의 정식 `vite.config.ts`는 유지했습니다. Git에서 제외한 `work/verify-web.mjs`에서만 `preserveSymlinks`와 React 경로를 지정하여 해당 확인 과정을 거치지 않고 빌드·화면 검증을 했습니다. 일반 명령이 이 작업 환경에서도 성공했다고 기록하지 않습니다.

사용자의 일반 PowerShell에서 README의 `pnpm build`와 `pnpm dev`를 실행해 확인해야 합니다. 동일한 문제가 발생하면 환경 원인을 먼저 확인합니다.

## 다음 실행 순서

1. Docker 호환 런타임을 준비하고 실행합니다.
2. 프로젝트 루트에서 `docker compose up -d --wait`를 실행합니다. 로컬 `.env`는 초기화돼 있습니다.
3. `scripts/Start-Backend.ps1 -Task integrationTest`로 실제 MySQL 통합 검증을 합니다.
4. README대로 API와 프론트엔드를 실행해 빈 선수 목록을 확인합니다.
5. 운영진 로그인과 선수 등록·수정을 첫 사용 가능한 기능으로 추가합니다.
