# 경기 기록 삭제

2026-10-14 사용자 요청. 감독·코치가 잘못 등록한 경기를 목록에서 삭제한다.

## 범위와 정책

- 활성 팀의 개인 계정 DIRECTOR·COACH만 삭제할 수 있다. 팀 코드 회원·MEMBER·팀 운영 권한 없는 서비스 관리자는 삭제할 수 없다.
- 외부 경기와 자체전 모두 하루 전체를 삭제한다. 투표·출석, 계획 스쿼드, 1~4쿼터, 실제 출전·득점·도움·교체 기록을 같은 트랜잭션에서 삭제한다. 선수·용병 명부와 다른 경기는 유지한다.
- 삭제 후 해당 경기의 기록은 출석률·득점 집계에서 제외된다. 감사용 변경 이력은 유지하지만 복구 기능은 제공하지 않으며 확인창에 명시한다. [변경 이력 정책](player-filters-and-match-history.md)
- 목록에서 확인한 version으로 삭제한다. 다른 운영진의 수정과 충돌하면 409로 거부하고 최신 목록을 표시한다. 타 팀 또는 없는 ID는 404이다.
- 처리 중 중복 요청과 화면 이동을 막는다. 응답을 받지 못하면 자동 재시도하지 않고 목록 확인을 안내한다.

## 화면 흐름

1. 감독·코치로 경기 기록 목록에 들어가면 각 경기 카드 아래에 **삭제**가 보인다. 조회 회원에게는 보이지 않는다.
2. 삭제를 누르면 **이 경기 기록을 정말 삭제할까요?** 확인창에 날짜·시간·상대 팀(자체전은 A팀 vs B팀)과 삭제 범위를 표시한다.
3. 기본 포커스는 **취소**다. 취소 또는 Escape는 기록을 그대로 유지한다. **경기 기록 삭제**를 눌렀을 때만 요청한다.
4. 성공하면 목록을 갱신하고 약 4초 동안 성공 알림을 표시한다. 마지막 페이지의 마지막 경기였다면 남아 있는 마지막 페이지로 이동한다.
5. 수정 충돌·이미 삭제됨·통신 오류는 별도 안내를 남기고 목록을 다시 불러온다.

## API와 확인 기준

`DELETE /api/v1/matches/{id}?version={version}` — CSRF와 `X-Team-Id` 필요, version은 0 이상 정수이며 필수. 성공은 204.

확인 기준: 감독/코치 허용, 회원·CSRF 누락·타 팀 차단, 오래된 버전 거부, 연결 기록 전체 삭제와 선수/다른 경기 보존, 확인 취소 시 무변경, 성공 알림, 빈 마지막 페이지 복귀. MySQL 검증은 실제 회원 DB와 분리한 일회용 DB에서 수행한다. 결과는 [검증 기록](verification.md)에 남긴다.
