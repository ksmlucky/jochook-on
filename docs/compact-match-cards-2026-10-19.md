# 최근 경기와 목록 카드 정리

2026-10-19 · 로컬 구현, 미배포. 운영 기준은 웹43e8fd6 / 가이드1.13이다.

## 화면과 규칙

- 홈의 최근 경기에서도 경기 목록과 같은 `쿼터별 기록 펼치기`를 제공한다. 운영진·회원 모두 자기 팀의 기존 조회 권한으로 확인한다.
- 팀명 vs 상대 팀명 오른쪽에 상태 태그를 둔다. 좁은 화면에서는 `기록 완료`, `02 작성 중`처럼 표시하고 전체 단계는 접근성 이름과 툴팁으로 유지한다. 긴 팀명은 줄바꿈한다.
- 카드 아래 한 줄에 `기록 보기`(작성 중인 목록에서는 `이어서 작성`)와 `쿼터별 기록 펼치기`를 둔다. 펼친 내용은 두 버튼 아래에 나온다. 접기와 기록 열기는 별도 버튼으로 중첩하지 않는다.
- 펼칠 때만 기존 경기 상세 API를 조회한다. 구간별 골·도움·실점, 전후반과 자체전 A/B팀, 예전 합계 표시는 기존 공통 컴포넌트를 재사용한다. 새로고침 후 버전이 바뀌면 상세도 갱신한다.
- 실점 `− / 숫자 입력 / +`는 같은 줄에 높이44px·여백0으로 정렬한다. 0~99와 미입력 처리·최종 스코어 합산 규칙은 유지한다.
- API·DB·집계·권한 변경 없음. ERD와 운영 인프라 그림은 변경 대상이 아니다.

## 사용자 가이드 반영안

운영용1.13은 현재 서비스와 일치하도록 유지한다. 다음 기능 배포 때 아래 변경을 공통 원고·역할별 HTML/PDF·앱 가이드에 함께 반영하고 PDF 전체를 렌더링한다.

- 회원·운영진의 홈 안내: “최근 경기의 팀명 옆에서 작성 상태를 확인해요. 아래의 **기록 보기**로 경기를 열거나 **쿼터별 기록 펼치기**로 골·도움·실점을 바로 확인해요.” 기존 ‘경기 기록 보기’ 버튼 이름을 ‘기록 보기’로 갱신.
- 경기 목록 안내: 기록 보기/이어서 작성과 펼치기가 같은 줄에 있다는 점 추가.
- 운영진 결과 안내: 실점 숫자 양옆의 −/+로 증감한다는 배치 설명. 회원의 실점 입력 권한은 추가하지 않는다.

## 검증

- 프론트288개 회귀 테스트, TypeScript·Vite 빌드 통과.
- 가상 운영진 자료로390px 홈 최근 경기 펼치기/접기·전반/후반·실점 확인. 320px 홈/경기 목록에서 가로 넘침 없음, 두 동작 버튼 높이44px·같은 y좌표 확인.
- 320px 결과 화면에서 실점 증가와 −/입력/+의 높이44px·같은 y좌표·여백0 확인.
- 실제 iPhone Safari·운영 자료 쓰기·배포·Java/MySQL 테스트는 미실행. 프론트 화면만 변경했다.
