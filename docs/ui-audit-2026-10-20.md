# 조축ON UI 검토 · 2026-10-20

상태: 로컬 수정 및 통합 검증 대상. 운영 반영 결과는 배포 검증 문서를 기준으로 확인한다.

## 검토 범위와 한계

UI 전문가가 전역 스타일·앱 레이아웃과 로그인, 홈, 선수단, 여러 명 입력, 경기 목록·보고서·입력, 선수 기록, 대회, 팀 관리, 사용 가이드의 소스 구조를 검토했다. 이전 배포에서 남긴 가상 경기 모바일 화면 `outputs/match-report-mobile-preview.png`도 확인했다.

이 보고서의 대비 값은 sRGB 상대 휘도로 계산한 수치다. 소스 확인과 기존 화면에서 확인한 사항, 실제 기기에서 아직 확인하지 못한 사항을 구분한다. 이번 변경의 320px·390px 브라우저 최종 검증과 배포 검증은 총괄 보고서에 합친다. 실제 iPhone/Safari, 야외 햇빛, 사용자 관찰 조사는 이 코드 검토로 검증한 것으로 간주하지 않는다.

## 현재 잘된 점

- 색상 토큰, 흰 표면, 그린 강조색이 화면 전반에서 반복되어 같은 앱이라는 인상이 유지된다. 포지션에 색과 약어를 함께 써 색에만 의존하지 않는다.
- 모바일 입력은 대부분 16px, 주요 버튼은 44px 이상이다. 카드가 작아도 핵심 조작 크기를 유지하려는 방향이 맞다.
- 선수단 카드/표, 선수 기록 간단 보기/표, 기간 필터, 접기 안내가 있어 정보량에 맞춰 볼 수 있다. 모바일 표는 내부 스크롤로 전체 화면 넘침을 피한다.
- 조회용 경기 보고서와 기록 수정이 분리되어 있다. 쿼터별 스쿼드는 첫 구간만 펼쳐 처음 읽는 부담을 줄인다.
- 저장 중·오류·빈 결과·초안 복원 상태에 문구가 있으며, 그린색만으로 성공이나 상태를 전달하지 않는다. 모션 줄이기 설정도 적용한다.

## 취향과 장기 과제

카드 둥글기·그린 테마·전체 폰트 교체는 현재 확인한 결함이 아니다. 이번에는 변경하지 않는다. 선수 사진·프로 스타일 로고 확대도 정보 밀도와 저장 비용을 늘리므로 별도 요구가 있을 때 검토한다.

CSS는 전역 기본 규칙 뒤에 기능·모바일 덮어쓰기가 많이 누적되어 있다. 당장 전체를 재작성하면 기존 모바일 보정이 깨질 위험이 있어 이번 배포에서는 범위를 한정한다. 이후 공통 버튼·필터·상태 배지·패널의 스타일 책임을 정리하면 새 기능마다 높이나 여백이 달라지는 것을 줄일 수 있다.

첫 실사용 경기 후에는 “경기 입력 중 실수한 조작”, “선수 찾는 데 걸린 과정”, “읽기 어려운 글자”를 사례별로 모으는 것이 새로운 화면을 계속 추가하는 것보다 우선이다. 실제 사용 자료 없이 개선 효과를 수치로 주장하지 않는다.
