## 확정한 규칙

- 새 대회 경기는 전반 30분과 후반 30분, 총 두 구간으로 입력한다. 화면에는 전반(1쿼터), 후반(2쿼터)으로 표시한다. 입력 단계 01~04는 그대로 유지한다.
- 전반 또는 후반을 전부 뛴 선수는 1쿼터, 한 자리에서 교체한 두 선수는 각각 0.5쿼터다. 대회 풀타임 출전은 2쿼터다. 리그와 합산할 때 분 단위로 환산하지 않는다.
- 정기 리그와 자체전은 기존 4쿼터다. 대회 전·후반은 30분으로 고정하고 구간별 시간 입력은 추가하지 않는다. 연장전과 승부차기는 이번 범위가 아니다.
- 대회 시간 범위는 시작 시각 +60분으로 표시한다. 휴식 시간은 별도이며 포함하지 않는다. 기존 4쿼터 일정은 시작 +2시간 표시를 유지한다.
- 자체전 01은 A팀 또는 B팀을 먼저 고르고 선수를 체크하면 참석 예정과 팀 배정을 함께 설정한다. 다른 팀의 선수는 중복 선택하지 않는다. 명시적인 팀 이동과 체크 해제는 기존 계획 정리 확인을 거치며 실제 출전·득점 기록은 보존한다.

## 기존 기록 보호와 API 계약

- `matchFormat`은 `FOUR_QUARTERS` 또는 `TWO_HALVES_30`이다. 형식을 대회 연결 여부와 별도로 저장해야 기존 기록의 의미를 보존할 수 있다.
- Flyway V28은 기존 경기를 모두 `FOUR_QUARTERS`로 유지한다. 예전 대회 경기의 3·4쿼터와 골·도움을 삭제하거나 2쿼터로 재해석하지 않는다.
- 기존 4쿼터 경기의 3·4쿼터 계획/실제 기록이 있으면 2구간 전환을 거절한다. 요청에서 그 데이터를 지우고 동시에 형식만 바꾸는 것도 저장된 원본을 기준으로 차단한다. 운영진이 별도로 확인·정리·저장한 뒤 전환해야 한다.
- 대회 연결을 해제해도 저장된 경기 형식을 유지한다. 자체전은 항상 4쿼터다.
- 구버전 생성 요청이 형식을 생략하면 4쿼터, 수정 요청이 생략하면 저장된 형식을 유지한다. 고정된 저장 재시도 요청의 본문과 지문을 바꾸지 않는다.
- 두 구간 형식의 실제 배열은 1·2만 한 번씩 포함하고 계획 역시 1·2만 허용한다. 자동 편성도 두 구간 전체를 계산하며 4쿼터 결과를 잘라 쓰지 않는다.
- 엑셀 양식과 미리보기는 선택한 형식을 전달한다. 두 구간 경기에 3·4쿼터 행을 업로드하면 명확하게 거절한다.

## 검증 기준

1. 신규 대회 선택 → 두 구간 자동 편성 → 실제 복사 → 교체·득점 → 저장·재조회에서 형식과 기록이 유지된다.
2. 기존 4쿼터 대회, 구버전 초안과 저장 재시도, 변경 이력은 원래 구간을 보존한다.
3. 4→2 전환의 기존 3·4쿼터 보호, 범위 밖 계획·실제·엑셀 행 거부, 다른 팀 조회·수정 차단을 확인한다.
4. 리그와 대회 합산·분리에서 득점·도움·0.5쿼터·출석을 대조한다. 1~4쿼터당 통계는 시간 보정 없이 실제 쿼터 합을 분모로 쓴다.
5. 자체전 A/B 체크·해제·이동·미배정·용병·저장·재조회, 계획 정리 확인과 실제 기록 보존을 확인한다.
6. 작은 화면의 구간 탭·팀 선택·한눈에 보기와 읽기 전용 회원 화면을 확인한다.
