# 선수 즉시 배치와 간결한 저장 버튼

2026-10-19 개발 기준. 사용자 요청으로 검증 후 웹 배포 예정이며 API·DB 변경은 없다.

## 동작과 화면 흐름

- 02 배치·기록 수정에서 자리 → 선수 목록 → 선수 누르기 → 즉시 초안 반영·편집창 닫기로 줄인다. 선발·교체, 일반 작전판·한눈에 보기에 공통 적용한다.
- 선수 목록 안에서만 이름 오름차순을 사용한다. 동명이인은 등번호, 선수 ID로 안정적으로 구분한다. 다른 명단 정렬은 유지한다.
- 이번 구간에 배치된 선수는 실제 배치 자리의 공격/미드/수비/키퍼 색상과 `CM (좌)` 같은 자리로 표시한다. `이동/교환` 문구는 없앤다. 현재 선택 상태는 접근성 속성으로 유지한다.
- 기존 기록과 충돌해 배치할 수 없으면 편집창을 닫지 않고 오류를 표시한다. 선수 선택만으로 서버에 저장하지 않는다.
- 고정 저장 영역은 오른쪽 아래 최대 244px로 축소한다. 버튼은 `저장·목록`, `저장·다음`, `기록 완료`이며 44px 이상의 터치 높이와 안전 영역을 확보한다. 저장 결과·작성 중 전환·완료 확인 정책은 유지한다.
