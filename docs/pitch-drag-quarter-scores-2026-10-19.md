# 작전판 드래그와 쿼터별 실점

운영 확인 2026-10-19 20:04:51 KST: API·웹 1519c9d, DB V32, 가이드1.12.

## 기능과 화면 흐름

1. 01 참석 → 02 스쿼드. 배치 수정/자리 바꾸기 선택을 없앤다. 자리 탭 → 이름순 선수 선택 → 즉시 초안에 배치한다.
2. 배치된 선수를 길게(380ms) 눌러 끌면 빈자리에 이동하거나 다른 선수와 교환한다. 누른 직후 세로로 움직이면 일반 스크롤이다. 마우스는 바로 끌 수 있다. 같은 구간·팀만 허용하며 한눈에 보기에서도 동일하다. 짧게 누르는 방식과 키보드 선택도 유지한다.
3. 선발 X/해제 시 기존 교체는 선발로 승격한다. 선발만 남으면 1쿼터로 계산한다. 제거할 선수의 골·도움이 있으면 기록 손실을 막고 안내한다. 이동 시 개인 기록은 선수를 따라간다.
4. 03에서 구간을 선택 → 골·도움 및 외부 경기 실점 입력 → 구간 기록 저장. 저장은 전체 경기 변경을 함께 저장하고 현재 구간을 유지한다. 완료는 별도이다.
5. 골 변경 시 최종 득점, 실점 변경 시 최종 실점을 전체 구간에서 다시 합산한다. 자체전은 A/B 골을 각각 합산하고 각 팀 실점은 상대 팀 골로 표시한다. 기존 경기 열기나 도움만 바꾸기는 수동 최종 스코어를 바꾸지 않는다. 자책골/미상 득점은 최종 스코어 직접 입력을 유지한다.

## 저장과 호환성

- V32: match_quarters.goals_against nullable INT, 0..99 CHECK. NULL은 미입력, 0은 무실점. 구간 시간 컬럼은 추가하지 않는다. 자체전에는 독립 실점을 저장하지 않는다.
- 이전 API 요청이 새 필드를 생략하면 기존 값을 보존한다. 명시적으로 비우려면 goalsAgainstSpecified=true를 함께 보낸다. 오래된 재시도 요청 지문도 유지한다.
- 미입력 실점 구간은 합산에서 제외하고 개수를 알린다. 자동 합산 결과는 현재 입력 범위의 합계이므로 모든 구간을 입력해야 최종 결과가 완성된다.
- 3/4쿼터 실점 기록이 있으면 전후반으로 변경해 기록을 잃지 않도록 막는다. 변경 이력은 실점의 이전/이후 값과 미입력/0을 구분한다.
