## 반영한 기능

- 대회 등록·수정, 경기 연결·단계 선택과 리그/대회 조회. 새 대회는 전반·후반 각 30분이며 기존 4쿼터 기록은 보존합니다.
- 자체전 01에서 A팀/B팀을 고른 뒤 선수를 체크합니다. 02 후보·자동 편성·직접 배치는 미리 정한 팀을 유지합니다.
- 3-5-2는 ST 2명·CAM·CM 2명·LWB/RWB·센터백 3명, 3-4-3은 LW/ST/RW·LM/RM·CM 2명·센터백 3명으로 배치합니다. GK는 별도 한 자리입니다.
- 선수별 상세와 원본 경기 연결, 시작/종료 연월·전체 기간, 리그/대회·특정 대회 필터와 표 제목 정렬을 제공합니다.
- FK/PK는 총득점에 포함된 세부 기록입니다. 누적 또는 1·2·3·4쿼터당 수치를 선택하고, 경기별 카드는 실제 골·도움을 표시합니다.
- 생년·가용 등번호 직접 입력과 목록 선택, 완료 전 점검 및 역할별 앱/PDF 가이드 1.2를 반영했습니다.

대회 풀타임은 2쿼터, 리그·자체전은 4쿼터이며 교체 두 선수는 각각 0.5쿼터입니다. 합산할 때 시간 환산은 하지 않습니다. 프로 선수 API 연동·비교는 보류 상태입니다.

## 배포와 복구 경계

1. 검증 커밋을 GitHub에 올리고 전체 CI 성공을 확인했습니다.
2. 운영 백업·복원 검증 후 구 API를 잠시 멈추고 백업과 운영 자료가 같은지 다시 확인했습니다.
3. 같은 무료 사양에서 새 API와 V28을 확인한 뒤 웹을 배포했습니다. 웹/API 모두 위 커밋의 완료 상태입니다.
4. 외부 HTTPS·권한·원본 보존과 실제 번들을 확인했습니다. 자동 배포는 계속 비활성입니다.

V26은 3백의 기존 자리 값을 바꾸므로 **구 API 이미지만 되돌리지 않습니다**. 새 기록이 생긴 뒤에는 먼저 별도 백업을 만들고 새 기록 보존을 포함한 복구 절차를 결정해야 합니다. 검증된 배포 전 사본은 Git 제외 `backups/northflank/20261015-before-tournament-expansion/`에 있습니다. DPAPI 사본은 이 Windows 사용자에 종속되며 자동 예약 백업이나 외부 독립 사본을 뜻하지 않습니다. 무료 daily 예약은 기존처럼 미설정입니다.
